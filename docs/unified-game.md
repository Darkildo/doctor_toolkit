# Единая игра

Одна и та же папка игры у всех, с какого бы издания ни начинали: данные диска
NTSC (эталон doctor_toolkit), исполняемый файл 1.0.789.0 и все языки, какие
есть на дисках. Собирается из своего диска или установленной копии и
**пакета** с тем, чего этому изданию не хватает.

## 1. Издания и языки

| | PAL, диск от 27.01.2009 | NTSC, диск от 19.02.2009 | Единая игра |
|---|---|---|---|
| Версия exe | 1.0.764.0 | 1.0.766.0 | 1.0.789.0 |
| Метка сборки (`text/localetable.txt`, строка 3) | `pal_en` | `ntsc_en` | `ntsc_en` |
| Озвучка | en, ru | en, es | en, es, ru |
| Текст | en, es, ru, cs, nl, pl | en, es | en, es, ru, cs, nl, pl |

Чего нет: французского и немецкого (их строки видны в служебной таблице
«Longest», значит, издания с ними существовали) — пакет пополняется, когда
найдётся диск.

**Проверено по дискам и в игре** (стенд `tools/game-bench.sh`, exe 1.0.789.0):

- PAL и NTSC — две сборки одних данных. У потоков мира разные сгенерированные
  идентификаторы ресурсов, поэтому потоки двух сборок не смешиваются, и моды
  для одной не подходят другой. База единой игры — NTSC.
- Строки одинаковы: 9 069 идентификаторов, английский текст совпадает
  побайтно. Потоки текста `gf2/text/<хэш>` самодостаточны и переносятся.
- Шрифты PAL содержат кириллицу и центральноевропейские буквы. В
  `gf2/frontend` и `gf2/globals_global` два `ffn` и два атласа `tg4h`/`tg4d`
  заменяются на месте. Шрифт ищет атлас по хэшу имени текстуры, поэтому в
  заголовке атласа PAL хэш (`+0x14`) заменяется на хэш NTSC: с хэшем PAL
  буквы рисуются сплошными прямоугольниками, со старым атласом — мусором.
- Язык игра берёт из строки `Locale = xx` файла
  `%LOCALAPPDATA%\EA Games\<название>\settings.txt`; пока строки нет — из
  значения `Locale` ключа `HKLM\SOFTWARE\EA Games\The Godfather II`
  (32-битная ветка). Строка в файле сильнее реестра. Код обрезается до двух
  букв (`0x00931FB0`).
- Exe 1.0.789.0 перед поиском языка превращает `cs` в `cz` (`0x0093200C`):
  чешский в таблице языков, в `lhr` и в `movies/` идёт под кодом `cz`.
- Русская озвучка лежит в отдельном архиве `GODFATH3.viv`
  (`audiostreams\ru\…`, 12 232 файла); в Гаване игра читает из него реплики.

## 2. Собрать игру

Программа `gf2-unify` — отдельный небольшой крейт `crates/doctor-toolkit-unify`
(библиотека и программа). От крейта `doctor-toolkit` он не зависит: чтение
установочных архивов диска и архивов `BIGF` лежит в нём самом.

Готовые сборки для Windows x86_64 и Linux x86_64 лежат в выпусках
репозитория с названием `gf2-unify <версия>` — отдельно от выпусков тулкита
(§2.4). Из исходников:

```sh
cargo build --release -p doctor-toolkit-unify      # target/release/gf2-unify
```

### 2.1 Окно

Запуск без аргументов (двойной щелчок) открывает окно на русском или
английском (по языку системы, переключатель справа вверху):

1. **Ваша копия игры** — папка диска (смонтированный образ) или
   установленной игры. Под полем сразу видно, что это за издание, или почему
   папка не подходит.
2. **Пакет** — папка с `unified.json`; папка `pack` рядом с программой
   подставляется сама. Пока пакета нет, окно показывает, где его взять:
   ссылку раздачи с кнопками «Скопировать ссылку» и «Открыть в
   торрент-клиенте». Под полем видно:
   - тот ли это пакет, что опубликован с программой («опубликованный пакет,
     выпуск N»). Программа знает SHA-256 манифеста каждого выпуска, а
     манифест называет хэш каждого файла игры. Для другого пакета кнопка
     сборки включается только галочкой «Я доверяю источнику этого пакета»;
   - все ли файлы, нужные вашему изданию, скачаны: если часть в раздаче не
     отмечена или не докачана, окно называет число файлов и часть.
3. **Куда собрать игру** — новая папка, не ваша копия.
4. **Язык игры** — текст и озвучка (у чешского, нидерландского и польского
   озвучка английская).

Кнопка **Собрать игру** доступна, когда все три папки годятся. Идёт полоса
хода с именем файла; в конце — папка игры и что сделано с языком. При ошибке
текст причины остаётся в окне, готовые файлы сохраняются, кнопку можно
нажать снова.

`gf2-unify window --source … --pack … -o …` открывает окно с заполненными
полями. Без окна программа собирается так:
`cargo build --release -p doctor-toolkit-unify --no-default-features`.

**Проверено** под Linux: окно, проверка папок, сборка по кнопке, итог (на
тестовых данных); на настоящем пакете — что он узнаётся, что пакет с одной
частью `for-ntsc` собирает игру из диска NTSC и что для копии PAL окно
называет недостающую часть. **Не проверено:** окно и установка языка под
Windows.

### 2.2 Язык

На Windows программа пишет `Locale` в реестр (спросит права администратора)
и в `settings.txt` игры, если он уже есть. Под Wine префикс игры программе
неизвестен: она показывает команду `wine reg add …`, которую нужно выполнить
в этом префиксе. Отдельно: `gf2-unify language ru`.

### 2.3 Командная строка

```sh
gf2-unify apply ПАКЕТ ИСТОЧНИК -o ПАПКА_ИГРЫ
gf2-unify verify ПАКЕТ ПАПКА_ИГРЫ     # сверить готовую папку
gf2-unify info ПАКЕТ                  # что пакет добавляет каждому изданию
```

`ИСТОЧНИК` — папка диска (смонтированный образ с файлами `data_*.cab`) или
установленная копия, PAL или NTSC; она только читается. Издание определяется
по метке сборки. Папка игры — новая, не источник (нужно 9,3 ГБ).

- Каждый файл источника сверяется по SHA-256 с манифестом: изменённый файл
  (мод, репак) в результат не попадает. Он берётся из пакета, если пакет его
  содержит, иначе команда называет такие файлы и останавливается.
- Звуковые архивы собираются по записям из архивов источника и архива
  пакета; итог сверяется целиком и побайтно равен архивам NTSC. Годится и
  копия, где архивы распакованы в папку `audiostreams/` (так делают
  некоторые репаки). Копия с вырезанной озвучкой не годится — нужен диск.
- Прерванный запуск продолжается: готовые файлы остаются.

Проверено на настоящих данных: из диска NTSC, из диска PAL и из
установленной копии PAL получается одна и та же папка (11–16 с на SSD);
она же проходит `gf2-unify verify`.

### 2.4 Выпуск программы

Версия программы своя (в `crates/doctor-toolkit-unify/Cargo.toml`). Тег
`gf2-unify-v<версия>` запускает `.github/workflows/unify-release.yml`: тесты
крейта, сборка для Windows и Linux, архивы с `README.txt` на черновике
выпуска. Выпуски тулкита (`v<версия>`) программу не содержат.

Новый выпуск пакета — новая строка в `KNOWN_PACKS` (`src/lib.rs`: номер,
SHA-256 файла `unified.json`, ссылка раздачи) и новый выпуск программы.

## 3. Пакет

```
unified.json    манифест: каждый файл единой игры (размер, SHA-256) и где он есть в каждом издании
common/         чего нет ни на одном диске: exe, изменённые потоки, таблица языков; мелкие файлы (до 64 КБ)
for-ntsc/       чего нет на диске NTSC: русская озвучка, ролики ru, cz, nl, pl      (1,5 ГБ)
for-pal/        чего нет на диске PAL: потоки NTSC, испанская озвучка, ролики es    (2,7 ГБ)
```

Пакет раздаётся торрентом (корень раздачи — папка `pack`); ссылка вшита в
программу. Владельцу диска нужны `common` и часть своего издания. С полным пакетом
изменённая копия чинится файлами другой части.

Пакет содержит данные игры, принадлежащие Electronic Arts. Он дополняет
купленную копию и без неё игру не даёт.

Команды `apply` и `info` тоже пишут, опубликованный ли это пакет; для
другого — предупреждение и ссылку на опубликованный.

Сборка пакета (сопровождающим; нужны оба диска и exe 1.0.789.0):

```sh
tools/unified-build/build.sh --ntsc ДИСК_NTSC --pal ОБРАЗ_PAL.iso --exe godfather2.exe \
    --work РАБОЧАЯ_ПАПКА --out ЕДИНАЯ_ИГРА --pack ПАКЕТ
```

Сценарий распаковывает установочные архивы дисков, собирает чистое дерево
NTSC (оно совпадает с эталоном тулкита по всем файлам), добавляет языки
командами тулкита и вызывает `gf2-unify pack`. Результат
воспроизводим: повторный запуск даёт тот же манифест.

## 4. Открытые вопросы

- Репаки без двух общих роликов (`movies/common/attract.vp6`, `credits.vp6`)
  не проходят: ролики есть на обоих дисках, и в пакет не входят.
- Меняется ли язык в самой игре (в exe есть `ShowLanguages`, `AddLanguage`),
  не проверено.
- Накладной звуковой архив тулкита (`docs/formats/audio.md` §4) сдвигает
  номера архивов игры на один; с четырьмя архивами это не проверено.
