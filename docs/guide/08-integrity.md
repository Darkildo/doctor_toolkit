# 8. Целостность и восстановление

## 8.1 Кто изменил файлы игры

```sh
doctor-toolkit integrity "$GAME"
```

В редакторе и в Open Mod Manager — кнопка **Check integrity**. Для
каждого потока и таблицы содержимого показывается состояние:

| Состояние | Значит |
|---|---|
| original | файл равен оригиналу |
| changed by the mod manager | записан менеджером модов |
| changed by the editor's workspace | записан из рабочего пространства |
| changed by the old toolkit | изменён старым тулкитом |
| changed by another program | изменён кем-то ещё (другим инструментом, вручную, обновлением игры) |
| differs from the reference list | отличается от сохранённого эталона |
| not verified | не с чем сравнить: ни резервной копии, ни эталона |

Проверка также называет установленные патчи старого тулкита и остатки
прерванной записи (`*.doctor-toolkit-tmp`; игра их не читает, их можно
удалить).

**Эталон.** На заведомо неизменённой игре сохраните размеры и хэши всех
файлов: `doctor-toolkit integrity "$GAME" --save-reference`. Потом
`integrity --full` сверит каждый файл по хэшу (читается вся игра, около 9 ГБ).

## 8.2 Возврат оригиналов

| Что вернуть | Команда | Окно |
|---|---|---|
| Всё, что когда-либо менял тулкит | `doctor-toolkit restore "$GAME"` | **Restore originals** (два щелчка) |
| Только записанное рабочим пространством | `doctor-toolkit workspace revert "$GAME" --game` | **Revert game** в окне Changes |
| Только записанное менеджером модов | `doctor-toolkit mods unapply "$GAME"` | **Restore originals** в окне Mods |

Правки рабочего пространства и установленные моды при этом сохраняются —
их можно записать снова.

Резервные копии лежат в `<игра>/_doctor_toolkit/backups/` с теми же путями,
что и в игре. Не удаляйте их, пока игра изменена: это единственные
оригиналы. Если копий нет, а файлы испорчены — проверьте файлы игры
средствами магазина (Steam: «Проверить целостность файлов игры») или
переустановите игру.
