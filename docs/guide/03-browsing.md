# 3. Просмотр

## 3.1 Как устроены файлы игры

Данные игры лежат в **потоках** (`.str`) — контейнерах из сотен или тысяч
**ресурсов**. Ресурс имеет тип (`tg4h` — заголовок текстуры, `tg4d` — её
данные, `mesh` — модель, `lh2` — таблица строк, `simgroup` — объекты уровня
и т. д.) и четыре идентификатора. **Таблицы содержимого** (`.toc`) говорят
игре, какие потоки грузить и какого они размера.

Ресурс однозначно называется **ключом** `поток:тип:ids`, например
`gf2/text/dd7d7050:lh2:9e583c54`. Ключи используют рабочее пространство, моды,
поиск и командная строка.

## 3.2 Окно редактора

- Слева панель **Files** — потоки и TOC игры с фильтром по имени. Щелчок
  открывает поток во вкладке, Ctrl+щелчок — в новой вкладке. Tools → **All
  resources** (Ctrl+Shift+R) — вкладка со всеми ресурсами игры и фильтром по
  типу.
- В середине — вкладки: ресурсы потока, поиски, отдельные ресурсы, уровни.
  Ctrl+щелчок и Shift+щелчок выделяют несколько ресурсов.
- Справа панель **Details** — выбранный ресурс: заголовок, имена, что он
  использует и что использует его (ссылки кликабельны), и просмотрщик.
  «Open in tab» (или двойной щелчок в списке) оставляет ресурс открытым в
  своей вкладке, чтобы сравнивать несколько.
- Внизу панели **Log** (сообщения) и **Changes** (правки). Панели можно
  прятать, перетаскивать и разворачивать — раздел [10](10-interface.md).

| Тип | Просмотр |
|---|---|
| Текстуры | масштаб и сдвиг, каналы R/G/B/A, шахматный фон, mip-уровни, сравнение с изменённой версией |
| Модели | 3D на видеокарте: вращение мышью, каркас, нормали, скелет, веса костей, части модели |
| Flash-интерфейсы (`apx`) | встроенные текстуры, данные |
| Риги (`rcb`) | дерево костей |
| Шрифты (`ffn`) | атлас глифов |
| Звуковые банки (`sbk`) | звуки → вариации → тоны и сэмплы, прослушивание, правка параметров, новые звуки (раздел 19), экспорт в WAV |
| Таблицы строк (`lh2`) | редактор строк по языкам |
| SimGroup | объекты уровня: фильтр по классу и имени, положение, модель, атрибуты, ссылки на другие объекты |
| Остальная логика | раскрывающееся дерево JSON |
| Прочее | шестнадцатеричный просмотр |

## 3.3 Поиск и переходы

**Search** (Ctrl+F) ищет по всей игре:

| Запрос | Что найдёт |
|---|---|
| `rust` | ресурсы, в имени которых есть слово |
| `car_*` | по шаблону |
| `38523fc3` | по хэшу или идентификатору |
| `type:material rust` | только материалы |
| `text:"Press any key"` | строки текста |
| `gf2/frontend:apx:…` | по ключу или его части |

Enter в поле поиска показывает результаты во вкладке поиска,
Ctrl+Shift+F открывает ещё одну. Результат открывается щелчком. **<** и
**>** (Alt+Left, Alt+Right) ходят назад и вперёд по истории переходов.
Палитра команд (Ctrl+Shift+P) находит ресурс по тем же запросам и сразу
открывает его.

В командной строке то же самое:

```sh
doctor-toolkit search "$GAME" type:material rust
doctor-toolkit refs "$GAME" gf2/frontend:tg4h:00000000.4802e0a7.f3d257db.9cf57f36
doctor-toolkit lookup 38523fc3 --game "$GAME"     # чьё это имя и где встречается
```
