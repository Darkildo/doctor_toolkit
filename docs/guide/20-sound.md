# 20. Звук

Звук игры — банки `sbk` в потоках (звуки меню, уровней, шагов, ударов) и
потоковые файлы в архивах `GODFATH*.viv` (речь, музыка). Формат —
`docs/formats/audio.md`.

## Из чего состоит банк

| Что | Смысл |
|---|---|
| **звук** (эмиттер, `.emx`) | то, что игра проигрывает по имени: `PlayEmx("fanfare.emx")` в скриптах, `audio: play` в событиях анимации. Параметры: громкость, случайные высота и громкость, дальность затухания, приоритет, сколько раз одновременно, 3D |
| **вариация** | один из вариантов звука; игра выбирает вариацию сама (случайно) или по номеру. Вариация — короткая программа: «нажать тон», «высота», «конец»… |
| **тон** | сэмпл с огибающей громкости |
| **сэмпл** | сами данные EA-XAS; один сэмпл могут играть несколько звуков |

Имена известны у 417 из 905 звуков игры (подобраны по хэшу), остальные
показываются хэшем (`473a3f62`).

## Просмотр и прослушивание

Выберите ресурс `sbk` (например, в потоке `gf2/frontend`). Вкладка
**Звуки** — список звуков с фильтром; раскройте звук: у каждой вариации —
кнопки её тонов, нажатие проигрывает сэмпл с высотой вариации. Вкладка
**Сэмплы** — все сэмплы банка: **Слушать**, **WAV…**, **Импорт…**.

```sh
doctor-toolkit sbk-info "$GAME" gf2/frontend:sbk:6d4bafbd             # все звуки банка
doctor-toolkit sbk-info "$GAME" gf2/frontend:sbk:6d4bafbd --emitter '#4' --json
```

## Правка параметров

В редакторе: выберите звук в дереве, поменяйте громкость, разбросы,
затухание и т. д., нажмите **Сохранить** (правка уходит в рабочее
пространство, в игру её пишет **Применить**). **Высота** — постоянная
высота всех вариаций (1 — как записано, 2 — на октаву выше), вместе с силой
нажатия задаётся кнопкой **Задать высоту и силу**. Если правка ломает
ссылки банка, ошибка показывается красным и сохранить нельзя.

```sh
doctor-toolkit sbk-edit "$GAME" gf2/frontend:sbk:6d4bafbd --emitter '#4' \
    --volume 0.5 --pitch 1.5 --pitch-range 0.1 --velocity 100
```

## Голосовые реплики

Речь лежит не в банках, а в архивах `.viv`; реплику персонажу добавляет
мастер **Новая голосовая реплика** (раздел 15.9) или команда:

```sh
doctor-toolkit voice-add "$GAME" --speakers        # наборы речи и их голоса
doctor-toolkit voice-add "$GAME" gf2/globals_global:chv:18c7062e hello.wav \
    --event DOCTOR_HELLO --name doc1_xxx_0000001 --subtitle en="Hello."
```

Таблица событий речи, категории звука и миксы:

```sh
doctor-toolkit speech-events "$GAME" F2F_ENJOY_FLIGHT          # пауза, ранг, флаги, приоритет
doctor-toolkit speech-events "$GAME" DOCTOR_HELLO --set --cooldown 30
doctor-toolkit audio-config "$GAME"                            # категории, пулы банков, даки
doctor-toolkit mix "$GAME"                                     # список миксов
doctor-toolkit mix "$GAME" global_f2f.mix                      # каналы микса
doctor-toolkit mix "$GAME" global_f2f.mix --category MUSIC --volume 0.2
```

Форматы — `docs/formats/audio.md` §13–§15 и `docs/formats/dialogues.md` §3–§6.

## Замена и добавление звуков

| Задача | Редактор | Командная строка |
|---|---|---|
| заменить сэмпл | вкладка **Сэмплы** → **Импорт…** | `sound-import "$GAME" 'gf2/frontend:sbk:6d4bafbd#11' new.wav` |
| ещё вариации звука | звук в дереве → **Добавить звук…** (можно выбрать несколько файлов) | `sound-add "$GAME" КЛЮЧ a.wav b.wav --emitter '#4'` |
| новый звук | поле **Новый звук** → имя → **Добавить новый звук…** | `sound-add "$GAME" КЛЮЧ beep.wav --new my_beep --like '#0'` |
| заменить речь или музыку | — | `sound-import "$GAME" 'audiostreams\…exa.snu' new.wav` (§9 формата) |

Файлы — WAV или любой формат, который читает ffmpeg; они приводятся к
каналам и частоте первого сэмпла звука. Новый звук берёт параметры
выбранного (или `--like`) и получает имя `<имя>.emx`; имя не должно
совпадать со звуком игры. Чтобы игра его проиграла, банк должен быть
загружен (банк `gf2/globalfolder/audio/emx_global_folder_stream` загружен
всегда), а скрипт — вызвать его по имени (узел **Play sound** визуальных
скриптов, раздел 17).

Проверка новых звуков в самой игре запланирована на этап 45.
