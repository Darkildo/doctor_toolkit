# 22. ИИ-помощник: игра через MCP

ИИ-помощник вроде Claude Code или Claude Desktop может сам смотреть файлы
игры: искать ресурсы, читать объекты уровней и миссий, идти по сообщениям
логики, находить строки и имена хэшей. Для этого у тулкита есть сервер
**MCP** (Model Context Protocol) — команда `doctor-toolkit mcp`. Помощник
запускает её сам и задаёт вопросы через неё.

По умолчанию сервер **только читает**: он ничего не пишет ни в игру, ни в
рабочее пространство, ни в проект. Два флага разрешают больше (§22.5):
`--allow-edits` — правки в рабочем пространстве (каждую можно отменить),
`--allow-game` — запись в файлы игры и запуск игры.

Устройство и полный список инструментов — `docs/mcp.md`.

## 22.1 Что понадобится

- программа `doctor-toolkit` из выпуска (глава 1) или собранная из
  исходников; полный путь к ней, например
  `/home/me/doctor_toolkit-0.1.0-linux-x86_64/doctor-toolkit`;
- папка игры (глава 2), например
  `/home/me/.local/share/Steam/steamapps/common/The Godfather II`.

Проверьте, что сервер запускается: он напишет одну строку в stderr и будет
ждать клиента. Закройте его Ctrl+D.

```sh
doctor-toolkit mcp "/путь/к/The Godfather II"
```

Индекс игры берётся из кэша, как у редактора; если его ещё нет, первый
вопрос помощника займёт около минуты.

## 22.2 Claude Code

Одна команда добавляет сервер (для текущего проекта; `--scope user` — для
всех):

```sh
claude mcp add doctor-toolkit -- doctor-toolkit mcp "/путь/к/The Godfather II"
```

Если `doctor-toolkit` не в `PATH`, укажите полный путь к программе. С
рабочим пространством в другой папке или с проектом мода:

```sh
claude mcp add doctor-toolkit -- doctor-toolkit mcp "/путь/к/игре" \
    --workspace /путь/к/workspace --project ~/mods/my-mod
```

Проверка: `claude mcp list` показывает `doctor-toolkit … ✓ Connected`, а в
сессии команда `/mcp` — сервер и его 47 инструментов (с флагами — больше). Удалить:
`claude mcp remove doctor-toolkit`.

Тот же сервер можно описать файлом `.mcp.json` в папке проекта (его
читает Claude Code):

```json
{
  "mcpServers": {
    "doctor-toolkit": {
      "command": "doctor-toolkit",
      "args": ["mcp", "/путь/к/The Godfather II"]
    }
  }
}
```

## 22.3 Claude Desktop

Откройте настройки → Developer → Edit Config (файл
`claude_desktop_config.json`: в Linux `~/.config/Claude/`, в macOS
`~/Library/Application Support/Claude/`, в Windows `%APPDATA%\Claude\`) и
добавьте сервер:

```json
{
  "mcpServers": {
    "doctor-toolkit": {
      "command": "/home/me/doctor_toolkit-0.1.0-linux-x86_64/doctor-toolkit",
      "args": ["mcp", "/home/me/.local/share/Steam/steamapps/common/The Godfather II"]
    }
  }
}
```

Путь к программе здесь нужен полный: Claude Desktop не видит `PATH`
терминала. Перезапустите Claude Desktop; в окне сообщения появится значок
инструментов с `doctor-toolkit`.

## 22.4 Что спросить

- «Что за игра подключена? Сколько в ней потоков и ресурсов?» — `game_info`.
- «Найди все SimGroup района Бонита», «где используется материал
  `brick_wall`?» — `search`, `resource_info`.
- «Покажи объекты уровня `gf2/miami/local/bonita/high/terrain010` рядом с
  точкой (−350, −20, 640)» — `level_objects`.
- «Кто слушает сообщение `iMsgNewCheckpointLoaded`? Что происходит дальше
  на два шага?» — `logic_graph`.
- «Чем заканчивается миссия `cp_010_030_mission_1`? Какие сообщения в ней
  никто не слышит?» — `logic_graph` со `scope`.
- «Найди реплики, где упоминается Фредо», «что за хэш `38523fc3`?» —
  `strings`, `lookup_hash`.
- «Что известно о шине сообщений? Какие вопросы по зонам ещё открыты?» —
  `kb_search` и `kb_note` (база знаний `docs/kb/`, см. `docs/kb/README.md`).
- «Покажи диалог `0823c6d1` целиком», «декомпилируй этот скрипт Lua» —
  `resource_json`.
- «Что я поменял в рабочем пространстве и что ещё не записано в игру?» —
  `workspace_status`, `workspace_diff`; с проектом — `project_status`.

Помощник также может прочитать описания форматов — ресурсы
`doctor-toolkit://docs/formats/*.md` (в Claude Code — упоминанием `@` в
сообщении).

Если редактор открыт, помощник видит, что в нём выделено, и может
показать там нужное:

- «Что у меня выделено в редакторе? Кто слушает сообщения этого объекта?»
  — `editor_selection`, затем `logic_graph`;
- «Покажи этот объект в 3D», «открой граф логики на нём» —
  `editor_show_object`; «открой ресурс в его потоке» — `editor_open`.

Пока игра идёт с модулем связи (кнопка «Играть» с живой связью или
`play` помощника), он читает её: «Где сейчас игрок? Какие объекты
рядом?» — `player`, `objects_near`, `live_status`.

## 22.5 Правки и игра

Флаги добавляются в конец команды, например:

```sh
claude mcp add doctor-toolkit -- doctor-toolkit mcp "/путь/к/игре" --allow-edits
claude mcp add doctor-toolkit -- doctor-toolkit mcp "/путь/к/игре" --allow-edits --allow-game
```

**`--allow-edits` — правки в рабочем пространстве.** Помощник правит то же
рабочее пространство, что и редактор (глава 4): файлы игры не меняются,
пока вы (или помощник с `--allow-game`) не запишете правки в игру. Каждая
его правка — **одна операция**: её видно в панели «Изменения» и в
`workspace_status`, «Отменить» в редакторе или просьба «отмени» её
убирает. После каждой правки помощник получает сравнение с оригиналом.

Что можно попросить:

- «Подними этот объект на метр», «скопируй его на 5 м правее», «удали
  копию» — `move_object`, `duplicate_object`, `remove_object`;
- «Поставь рядом с игроком такую же коробку-триггер, как в задании c67» —
  `add_object` (образец из любой SimGroup, модель — та же, другая или
  копия с собственной коллизией);
- «Пусть этот MultiManager шлёт `my_message`» — `set_attribute`;
- «Поменяй реплику Фредо», «добавь строку `my_hint` на всех языках» —
  `edit_string`, `add_string`;
- «Сделай скрипт: по сообщению `doctor_ping` затемнить экран» —
  `edit_script` (граф узлов, как в редакторе скриптов, глава 17);
- «Добавь узел навигации здесь и свяжи с соседними» — `graph_edit`;
- «Проверь правки», «собери мод» — `validate`, `mod_build` (файл
  появляется в папке `mods/` рабочего пространства); с `--project` —
  «собери проект» (`project_build`);
- «Сделай новую зону рядом с воротами в Гаване и поставь туда мою модель
  стены из `wall.glb` с коллизией» — `add_stream` (новый поток),
  `add_simgroup` (группа объектов в нём), `import_model` (модель из файла
  новым набором в этот поток, с коллизией `box`, `hull` или `mesh`),
  `add_object` (объект с этой моделью), `validate`; с `--allow-game` —
  `play` и `stream_load` нового потока, чтобы проверить в игре;
- «Сделай так, чтобы эта зона сама загружалась, когда игрок подходит» —
  `add_zone_cell` (поток вносится в мировую сетку уровня: игра грузит его
  рядом с коробкой зоны и выгружает вдали, как свои зоны);
- «Перекрась эту текстуру картинкой `red.png`», «замени этот звук»,
  «поставь свой ролик вместо заставки», «поменяй субтитр реплики» —
  `import_texture`, `import_sound`, `import_video`, `edit_subtitle`;
- «Свяжи этот триггер с тем менеджером» — `logic_connect`;
- «Покажи ролик `igc16`», «подними камеру второго кадра на метр и поставь
  объектив 28 мм», «сдвинь Доминика влево», «покажи первый субтитр
  раньше» — `cutscenes` (список роликов, кадр, где камера и актёры в
  момент), `cutscene_camera`, `cutscene_actor`, `cutscene_command`,
  `edit_subtitle` с `line` (глава 16). Время субтитра делает изменением
  весь звуковой файл ролика — мод с ним весит мегабайты, помощник это
  видит в ответе;
- «Собери мод с моим модулем `my_mod.dll`» — `mod_build` с `native`;
  помощник соберёт и поставит мод, но **разрешить запуск кода не может**:
  это делаете вы в окне менеджера модов (глава 7);
- «Выгрузи таблицу строк, я поправлю» — `export` в JSON (нужен флаг
  `--output-dir`, см. ниже), затем `import_file` с исправленным файлом;
  так же для SimGroup, partsdb, навигационных графов, диалогов и Lua.

Помощнику, который должен класть файлы (модели в glTF, текстуры в PNG,
звуки в WAV, кадры роликов), дайте папку: `--output-dir /путь/к/папке`.
Без неё `export` и `media` отказывают; пишут они только в неё.

**Пока рабочее пространство открыто в редакторе**, писать в него может
только он. Когда помощник хочет правку, редактор показывает окно
«ИИ-клиент просит изменить рабочее пространство» с описанием правки:
«Разрешить» — правка записывается и сразу видна в редакторе, «Отмена» —
помощник получает отказ, ничего не записано. Без открытого редактора (или
со старой версией) помощник получает понятную ошибку «open for writing in
the editor». То же для команд CLI: пока команда пишет, правки помощника
ждут её конца.

**`--allow-game` — игра.** Помощник может:

- записать рабочее пространство в игру и вернуть оригинальные файлы —
  `apply`, `unapply` (резервные копии, как у кнопки «Записать в игру»);
- управлять менеджером модов — `mods_manage` (установить, включить,
  выключить, порядок, записать в игру; поставить рабочее пространство
  модом, сохранить мод файлом, наборы модов); посмотреть моды, заглянуть
  в файл мода до установки, узнать состояние исполняемого кода модов и
  проверить файлы игры можно и без флагов — `mods`, `integrity`;
- запустить игру — `play`: на **собственном невидимом X-сервере** (на
  рабочем столе ничего не появляется; нужен пакет `xvfb`), с записанными
  правками, сразу в городе и у точки появления, с DXVK; он ждёт загрузки
  уровня. Способ запуска — тот же, что в настройках «Играть» редактора
  (Wine с вашим префиксом и т. п.); лаунчеры (Steam) не подходят, их окно
  появилось бы на экране;
- посмотреть на игру — `screenshot` (кадр приходит картинкой);
- действовать в ней через живую связь — `teleport`, `send_message`, `lua`;
  менять время суток, деньги, переменные сюжета и загружать потоки по
  одному — `set_time`, `set_money`, `set_variable`, `stream_load`,
  `stream_unload` (прочитать — `game_state`, `variables`, без флагов);
- отлаживать её — `pause`, `resume` (с `step` — один кадр),
  `breakpoints` (остановить игру на сообщении, на напечатанном тексте, на
  ошибке Lua); читать журнал игры — `game_log` (без флагов): печать Lua,
  ошибки со стеком, сообщения шины. Остановленная игра стоит, пока её не
  отпустят (`resume`), но не дольше двух минут (срок задаётся);
- смотреть уровень из любой точки — `camera` (свободная камера) и
  `screenshot`; начать игру в любой точке уровня — `play` с `position`
  (в рабочем пространстве появляется точка появления, нужен и
  `--allow-edits`);
- отправить перекрашенные текстуры в запущенную игру без перезапуска —
  `push_textures`;
- после вылета игры прочитать отчёт — `crash_reports` (без флагов);
- остановить — `stop`: игра закрывается (и стоящая на паузе тоже),
  `cmd.txt`, модуль связи и DXVK убираются, правки вынимаются из игры.
  То же происходит, если помощник отключился.

Перед действиями в игре хороший помощник спросит вас; инструкции сервера
просят его об этом. Пока игра идёт, `apply` и `unapply` не работают.

**То, что раньше умел только редактор** (этап 104). Помощник может:

- сделать то же, что мастера главы 15: поменять параметры игры из списка
  (`tunables`, `set_tunables`), добавить часть одежды и разрешить её
  наборам (`partsdb_add_part`, `partsdb_allow`), задать оттенки материала
  (`set_material`), перекрасить все копии текстуры (`import_texture` с
  `all_copies`), добавить голосовую реплику (`voice_add`);
- править звук и анимации: параметры и новые звуки банка (`sbk_edit`,
  `sound_add`), таблицы речи (`speech`, `set_speech_events`), микшер
  (`mix`, `set_mix`), клипы, их события и граф узлов (`import_animation`,
  `clip_events`, `animation_graph`, `set_animation_graph`), части роликов
  интерфейса (`apx_edit`);
- проверить без игры: прогнать логику миссии (`logic_run`) и скрипт
  (`script_run`), узнать, где земля и пройдёт ли игрок (`ground`,
  `walk_route`), поставить объекты на землю (`on_ground`), заглянуть в
  сохранение (`save_info`);
- работать с файлами: распаковать потоки в папку и записать изменённые
  файлы обратно (`unpack`, `pack`), завести проект (`project_new`,
  `project_pull`), убрать одно изменение (`revert`), вернуть оригиналы
  всех файлов игры (`restore_originals`, с `--allow-game`).

Файлы помощник пишет только в папку `--output-dir`. Вид уровня картинкой
он не получает — только то, что можно сказать числами: объекты у точки,
земля, маршрут.

## 22.6 Безопасность

- Сервер работает на вашем компьютере, по stdio, без сети.
- Он не принимает путей к файлам: только имена потоков и ключи ресурсов
  игры. Читает папку игры, рабочее пространство и проект, которые вы
  указали при запуске.
- Тексты игры и модов приходят помощнику огороженными как данные
  (`<game-data>`), с предупреждением не выполнять инструкции из них.
- Большие ответы приходят частями; предел одного ответа —
  `--max-response-chars` (40 000 символов по умолчанию).
- Без флагов единственное, что сервер может записать, — кэш индекса в
  `~/.cache/doctor-toolkit/`, как и редактор; `--no-cache` отключает и его.
  С `--allow-edits` пишется только рабочее пространство, с
  `--allow-game` — ещё файлы игры (с резервными копиями) и временные
  файлы запуска.
- Согласие на исполняемый код мода и на модуль отчётов о падениях
  помощник дать не может: у сервера нет такого действия. Мод с кодом он
  поставит, но код будет ждать вашего ответа в менеджере модов; мод с
  другим кодом поверх уже разрешённого он не поставит вовсе.
- Мост с редактором — локальный сокет в папке настроек
  (`~/.config/doctor-toolkit/editor.sock`), не сеть; переменная
  `DOCTOR_TOOLKIT_BRIDGE=off` при запуске редактора отключает его.

## 22.7 Неполадки

| Что видно | Что сделать |
|---|---|
| `Failed to connect` в `claude mcp list` | запустите ту же команду в терминале: ошибка (нет папки игры, это не игра) будет в stderr |
| первый ответ идёт минуту | строится индекс игры; дальше он берётся из кэша |
| помощник не видит свежих правок игры после `workspace apply` | индекс читается при запуске сервера: перезапустите его (`/mcp` → reconnect в Claude Code) |
| ответ обрезан | попросите следующую страницу (`offset`) или часть (`pointer`), либо увеличьте `--max-response-chars` (Claude Code по умолчанию принимает до 25 000 токенов) |
| помощник не видит инструментов правки | сервер запущен без `--allow-edits` (или `--allow-game`): добавьте флаг и переподключите сервер |
| «open for writing in the editor» | рабочее пространство открыто в редакторе без моста (старая версия, Windows): правьте в редакторе или закройте в нём игру |
| окно в редакторе не появляется | редактор свёрнут или мост выключен (`DOCTOR_TOOLKIT_BRIDGE=off`); помощник ждёт ответа до 3 минут |
| `play`: «Xvfb is needed» | установите пакет `xvfb` (Arch: `xorg-server-xvfb`) |
| `play`: «starts it through another program» | в настройках «Играть» выберите Wine, Proton или прямой запуск вместо Steam/лаунчера |
| `play` ждёт и пишет `loaded: false` | без загрузчика ASI нет живой связи — посмотрите `screenshot`; без DXVK под Wine игра грузится медленно (1–2 кадра в секунду) |
