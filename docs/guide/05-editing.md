# 5. Правка через рабочее пространство

## 5.1 Как это устроено

Каждая правка записывается в **рабочее пространство** — каталог
`<игра>/_doctor_toolkit/workspace/` с новыми данными ресурсов и историей
операций. Файлы игры при этом не меняются. Правки переживают перезапуск
программы, их можно отменять, сравнивать с оригиналом, собирать в мод и
записывать в игру одной командой.

Запись в игру (**Apply to game**, `workspace apply`):

1. проверяет все правки до первой записи (формат, размеры, лимиты контейнера);
2. копирует оригинальный файл в `_doctor_toolkit/backups/`, если копии ещё нет;
3. пересобирает поток из оригинала со всеми правками и заменяет файл
   атомарно (временный файл и переименование: прерванная запись не портит
   игру);
4. обновляет размеры потока во всех таблицах содержимого.

**Прямой режим** (флажок **Write to game at once** в редакторе, `--direct` в
командной строке) делает то же сразу после каждой правки.

## 5.2 Текстуры

В редакторе: выберите текстуру → **Import…** → файл DDS или PNG. Новая
текстура показывается рядом с оригиналом.

```sh
doctor-toolkit texture-import "$GAME" gf2/frontend buttons buttons.png
```

- **PNG** кодируется в формат оригинала (DXT1, DXT5, нормали DXT5_NM…) с
  полной цепочкой mip-уровней. Размер может отличаться от оригинала (не
  больше 4096×4096); берите стороны — степени двойки, как у текстур игры.
  Кубические и объёмные текстуры импортируются только из DDS.
- **DDS** берётся как есть: формат из того же семейства (DXT1 → DXT1, DXT5 →
  DXT5) или любой поддерживаемый (DXT1, DXT5, L8, A8, L8A8, RGBA8). Форма
  (обычная, кубическая, объёмная) должна совпадать. DDS с заголовком DX10 не
  поддерживаются — сохраняйте как «legacy DXT1/DXT5».

## 5.3 Тексты

В редакторе таблица строк (`lh2`) открывается в редакторе строк; **Save**
записывает изменения в рабочее пространство, изменённые строки подсвечены.

Командная строка: экспорт, правка JSON в любом редакторе, импорт.

```sh
doctor-toolkit text-export "$GAME" -o text
# правим text/gf2/text/dd7d7050/00000_lh2_9e583c54.json
doctor-toolkit text-import "$GAME" text/gf2/text/dd7d7050/00000_lh2_9e583c54.json
```

Шрифты игры содержат только латиницу: русский текст пока отобразится
пустыми местами (перевод — отдельный этап плана).

## 5.4 Распаковка и упаковка

```sh
doctor-toolkit unpack "$GAME" -o work --stream gf2/frontend
# правим PNG, JSON таблиц строк, сырые файлы в work/
doctor-toolkit pack "$GAME" work
```

В редакторе: выделите ресурсы и File → Unpack selected…, после правки —
File → Pack folder into workspace….

`pack` записывает в рабочее пространство только изменённые файлы и сначала
проверяет все: если какой-то файл нельзя импортировать (например, glTF модели
или JSON логики — в `pack` они только для чтения; модели возвращает
`model-import`, §5.5), не записывается ничего.

Любой ресурс можно заменить сырыми данными:

```sh
doctor-toolkit replace "$GAME" gf2/frontend --index 17 --data new.apx
```

## 5.5 Модели

Модель, выгруженную в glTF, FBX, OBJ или USD (`models`, глава 4) и изменённую в Blender или
другом редакторе, можно вернуть в игру, как и полностью новую модель:

```sh
doctor-toolkit model-import "$GAME" gf2/globalfolder/characters/allcharacters fringe_dress_lod2 dress.glb --dry-run
doctor-toolkit model-import "$GAME" gf2/globalfolder/characters/allcharacters fringe_dress_lod2 dress.glb
```

В редакторе — кнопка **Import model…** у ресурса `mesh` или `metamodel`:
окно показывает части, кости, материалы, предупреждения и предпросмотр.
Кости сопоставляются со скелетом игры по именам, поэтому имена костей и
материалов из экспорта нужно сохранять. `--new ИМЯ` добавляет модель как
новый набор, не трогая исходную. Подробности и ограничения —
`docs/model-import.md`.

### Анимации

Анимации персонажей лежат в банках `bnk`; их клипы, именованные входы
(имена, по которым игра просит анимацию: `idle`, `locomote_base`…) и ключ
банка печатает `anim list`. Клип выгружается в glTF, FBX или USD (`anim export`, глава 4),
правится в Blender (или берётся чужая анимация человека: кости
сопоставляются по именам, оси и пропорции другого скелета учитываются) и
возвращается:

```sh
doctor-toolkit anim list "$GAME" gf2/globals_global 2657
doctor-toolkit anim import "$GAME" gf2/globals_global:bnk:c0e2841d wave.glb --clip idle --dry-run
doctor-toolkit anim import "$GAME" gf2/globals_global:bnk:c0e2841d wave.glb --clip idle
doctor-toolkit anim import "$GAME" gf2/globals_global:bnk:c0e2841d wave.glb --clip my_wave --add
```

Замена клипа видна везде, где игра его играет. Новый клип (`--add`)
получает вход со своим именем, но игра сама его не попросит: нужен предмет
`InterestingObject` с этим именем (атрибут 6, `simgroup-set`) или вход с
именем существующей анимации и большим `--priority` в банке, который
загружается позже. Игра проигрывает клипы с частотой 29,97 кадра в секунду;
кости, которых нет в файле, остаются в позе привязки (команда предупредит).
События клипа (звуки шагов и т. п.) печатает и заменяет `anim events`
(`--set events.json`, время в тиках — 2 на кадр).

В редакторе: вид банка `bnk` — кнопка **Import clip…**: заменить выбранный
клип или добавить новый, **Preview** показывает анимацию на скелете,
**Apply** записывает правку. Подробности — `docs/formats/characters.md` §6.

## 5.6 История, сравнение, применение

| Действие | Редактор | Командная строка |
|---|---|---|
| Список правок и их состояние | панель **Changes** (Ctrl+3, кнопка Changes на панели инструментов) | `workspace status "$GAME"` |
| Что изменилось | панель Changes: байты, строки, текстуры рядом | `workspace diff "$GAME" [КЛЮЧ]` |
| История | панель Changes | `workspace log "$GAME"` |
| Отменить, вернуть | Ctrl+Z, Ctrl+Shift+Z, Edit → Undo/Redo | `workspace undo`, `workspace redo` |
| Записать в игру | **Apply to game**, Tools → Apply changes to game | `workspace apply "$GAME"` |
| Убрать правку | **Revert this change** | `workspace revert "$GAME" КЛЮЧ` |
| Вернуть оригиналы в игру, сохранив правки | **Revert game** | `workspace revert "$GAME" --game` |

Состояния правки: *pending* — ещё не в игре, *applied* — в игре, *conflict* —
файл игры изменила другая программа. Конфликтный поток перезаписывается
только с `apply --force`.

Проверить правку в игре: закройте редактор или нажмите **Apply to game**,
запустите игру, потом при необходимости **Revert game**.

Рабочее пространство можно держать вне каталога игры:
`--workspace-dir DIR` у команд правки, `workspace init "$GAME" --dir DIR`.
Устройство файлов — `docs/workspace.md`.
