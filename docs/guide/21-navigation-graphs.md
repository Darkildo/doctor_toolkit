# 21. Навигационные графы (пути ИИ)

По навигационным графам (`graph`) ходят и ездят персонажи игры: пешеходы,
машины и парковка, патрули, наземный поиск пути, звуковая окклюзия. Граф —
узлы с радиусом и рёбра между ними; рёбра могут вести в узлы соседних
графов. Формат — `docs/formats/navigation-graph.md`.

## Показ в уровне

Откройте уровень (Ctrl+L), загрузите зоны и раскройте в панели **Зоны** раздел
**Навигационные графы (пути ИИ)**. **Показать** рисует графы загруженных зон
поверх сцены:

| Цвет | Что |
|---|---|
| зелёный | наземный поиск пути |
| бирюзовый | пешеходы |
| оранжевый | патруль |
| синий | машины |
| фиолетовый | парковка |
| серый | звуковая окклюзия |
| тёмно-синий | ребро, где нужно перелезть, подняться по лестнице или спрыгнуть |
| белый | пешеходный переход |
| чёрный | выключенный узел |
| жёлтый | выбранный узел и его рёбра |

У одностороннего ребра на конце стрелка. **Тип** оставляет на экране графы
одного типа.

## Правка

С флажком **Выбирать узлы** щелчок рядом с узлом выбирает его (узлы
выбираются раньше объектов). Затем:

- **сдвинуть** — гизмо (стрелки осей, Ctrl — шаг 0,5 м) или поля X, Y, Z;
- **соединить** — Shift + щелчок по другому узлу того же графа (с флажком
  **В обе стороны** — два ребра);
- **флаги ребра** — флажки у ребра в списке; **✕** удаляет ребро;
- **выключить узел**, **радиус**;
- **Удалить узел** (второй щелчок подтверждает) — вместе с его рёбрами;
  рёбра других графов в этот граф перенумеровываются сами;
- **тип графа** — флажки над полями узла (ground, ped, patrol, vehicular…)
  меняют тип всего графа выбранного узла;
- **Rebuild R-tree** — построить дерево поиска графа заново по его узлам
  (нужно после правок графа другими инструментами).

**Подключить выбранный объект** — новый узел у выбранного объекта уровня,
связанный с ближайшими узлами (не дальше **в пределах**, не больше **рёбер
≤**) ближайшего показанного графа: так ИИ сможет подойти к вашему новому
объекту. **Узел перед камерой** — то же в 10 м перед камерой.

Длины рёбер, R-дерево и таблица кратчайших путей пересчитываются сами.
Каждая правка — одна запись рабочего пространства: Ctrl+Z отменяет, в игру
её пишет **Применить**.

> В игре пересобранный граф пока не проверен (этап 45). Держите правки в
> рабочем пространстве и проверяйте их в игре.

## Командная строка

Ключ графа — `поток:graph:id1.id2.id3.id4` (как в `list`).

```sh
K=gf2/miami/local/betsy/high/terrain1:graph:37c8a18f.1c9d14bb.56414843.39315a45
doctor-toolkit graph-info "$GAME" $K --nodes            # сводка и узлы с рёбрами
doctor-toolkit graph-export "$GAME" $K -o graph.json    # JSON
doctor-toolkit graph-import "$GAME" $K graph.json       # обратно (длины и пути пересчитаются)
doctor-toolkit graph-edit "$GAME" $K --move 3:-424,-20.9,54 --link 3:9 --two-way
doctor-toolkit graph-edit "$GAME" $K --attach=-400,-21,40 --max-links 2
doctor-toolkit graph-edit "$GAME" $K --remove-node 12 --direct
```

В проекте (глава 19) граф — файл `graph/<имя>.json`; сборка проекта тоже
приводит длины, R-дерево и пути к правке. Из Python —
`doctor_toolkit.navigation_graph(data)` и `navigation_graph_bytes(graph)`.
