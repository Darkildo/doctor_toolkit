# Руководство пользователя doctor_toolkit

doctor_toolkit — открытый инструмент для файлов игр на движке EARS. Первая
поддерживаемая игра — **The Godfather II (PC)**. Он показывает и экспортирует
ресурсы игры (текстуры, модели, звук, тексты, игровую логику), позволяет
править их с историей изменений, собирать и ставить моды.

В поставке три программы:

| Программа | Для кого | Что делает |
|---|---|---|
| `doctor-toolkit-gui` | моддеры | графический редактор: просмотр, поиск, экспорт, импорт, правки, моды |
| `doctor-toolkit` | моддеры, скрипты | командная строка: всё то же и пакетная работа |
| `doctor-toolkit-mods` | игроки | только менеджер модов: установить, упорядочить, включить, применить, откатить |

## Главное за минуту

- Тулкит **ничего не пишет в игру, пока вы не попросите**: правки копятся в
  рабочем пространстве, в игру их записывает **Apply to game**
  (`workspace apply`).
- Перед каждой записью оригинальный файл копируется в
  `<игра>/_doctor_toolkit/backups/`. **Restore originals** (`restore`)
  возвращает всё как было.
- Закройте игру, прежде чем менять её файлы: пока она запущена, редактор и
  менеджер модов в неё не пишут. **Play** (F5) запускает игру, по желанию
  записав изменения перед запуском и вернув оригиналы после.
- Мод — один файл `.zip`. Игроку достаточно `doctor-toolkit-mods`.

Подробные описания форматов и устройства — в `docs/workspace.md`,
`docs/mods.md`, `docs/navigation.md`, `docs/viewers.md` и `docs/formats/`.
