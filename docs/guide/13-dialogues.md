# 13. Диалоги

Разговоры лицом к лицу (F2F) — разговоры с NPC, где игрок выбирает ответ, —
хранятся деревьями `dlg` в потоках `gf2/globalfolder/dlg/<хэш>`. Редактор
диалогов открывается сам, когда в потоке выбран ресурс `dlg`. Как устроены
файлы — `docs/formats/dialogues.md`.

## 13.1 Что показывает редактор

Сверху — имя диалога, число узлов, реплик и выборов и язык текстов (`en`,
`es` …, по таблицам строк игры). **Started by N SimGroup object(s)** —
объекты логики, которые начинают этот разговор (`NPC`, `ChangeNPCSettings`,
`ChangeDialog`); **Open** открывает их SimGroup.

Слева — дерево разговора от первого узла:

| Цвет | Узел |
|---|---|
| синий | реплика: кто говорит (Player или NPC), событие речи и первый найденный субтитр |
| оранжевый | выбор игрока; под ним ветви с текстом вариантов в квадратных скобках |
| зелёный | условие (`if == var 0xe, false`; ветви `[true]` и `[false]`), присваивание, флаг NPC |
| серый | конец; `-> #17` — переход к узлу, показанному выше |

Узлы, до которых нельзя дойти, собраны внизу с пометкой `[not reached]`.

Справа — выбранный узел.

- **Реплика**: говорящий, событие речи (`INFO_MED_LEFT_LINE1`), клипы
  анимации и список записей речи с субтитрами. Имя события общее у многих
  персонажей; какая запись прозвучит, решает набор речи (`chv`) говорящего.
  Первыми стоят записи персонажей из тех же мест, где диалог начинается, и
  для игрока — голос Доминика. У прохожих субтитров нет.
- **Выбор**: время на ответ (−1 — без ограничения) и до пяти вариантов: имя
  строки (`hud_csa_f2f_choicea`), её текст на выбранном языке и узел, куда
  ведёт вариант.
- **Условие и присваивание**: номер переменной, тип и значение.
- **Branches**: куда ведёт каждая ветвь; **Go** переходит к узлу.

## 13.2 Правка

Каждое действие — отдельная операция рабочего пространства: **Ctrl+Z**
отменяет её, **Apply to game** записывает в игру.

| Что | Как |
|---|---|
| Текст субтитра реплики | исправить текст под записью и **Save**. Файл речи с новым субтитром попадает в накладной архив `GODFATH0.viv`, звук не меняется |
| Звук реплики | **Replace…** у записи: WAV (или MP3, OGG, FLAC) перекодируется как в `sound-import`; субтитры остаются. **WAV…** сохраняет запись в файл |
| Говорящий, событие речи | переключатель Player/NPC; имя или хэш события и **Set** |
| Текст варианта | исправить текст и **Save** — меняется строка в таблице выбранного языка |
| Новая подпись варианта | вписать новое имя строки и **Set**, затем текст и **Add string**: строка добавится во все языки (как `text-add`) |
| Порядок вариантов | **Up** / **Down** — вариант меняется местами с соседним вместе со своей ветвью |
| Связи | в **Branches** выбрать другой узел для ветви или «–» |
| Новая реплика | **Insert line after**: копия реплики (или первой реплики диалога) встаёт на первую ветвь узла; затем поменять событие речи |
| Удалить узел | **Remove node**: ветви, которые вели к нему, ведут к его первой ветви. Выборы, конец и первый узел не удаляются |

Новая реплика использует существующее событие речи: своё событие с новой
записью (`chv`, `smb`) тулкит пока не создаёт. Чтобы реплика сказала что-то
своё, замените звук и субтитр у её записи.

## 13.3 Поиск

Строка **Search all dialogues** ищет во всех диалогах игры: тексты
вариантов, имена событий речи, английские субтитры, имена клипов и номера
переменных. Результаты своего диалога ведут к узлу (`#13`), чужого —
открывают его (**Open**).

## 13.4 Командная строка

```sh
doctor-toolkit dialogues "$GAME"                     # все диалоги и кто их начинает
doctor-toolkit dialogues "$GAME" --search "Rosato"   # поиск
doctor-toolkit dialogue "$GAME" 0c6576f0             # дерево с речью и субтитрами
doctor-toolkit dialogue "$GAME" 0c6576f0 --json > d.json
doctor-toolkit dialogue-import "$GAME" d.json        # правленое дерево (поле data)
doctor-toolkit dialogue-export "$GAME" -o dialogues
doctor-toolkit subtitle "$GAME" 'audiostreams\b4_xxx_0\d_mob4_xxx_0001cc7.exa.snu' --set en="New line"
```

Все команды правки пишут в рабочее пространство; `--direct` сразу
применяет изменения к игре.
