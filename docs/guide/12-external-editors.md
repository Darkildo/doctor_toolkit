# 12. Внешние редакторы и Blender

Текстуру удобно рисовать в GIMP или Krita, таблицу строк — править в
LibreOffice Calc, скрипт — в любимом текстовом редакторе, модель — в
Blender. Тулкит открывает ресурс в такой программе и **сам импортирует
каждое сохранение** в рабочее пространство: сохранили в GIMP — текстура в
редакторе уже новая.

## 12.1 Какие программы

Edit → **Preferences… → External editors**: команда для картинок, моделей и
текста. `{file}` в команде — файл; пустое поле — программа, которая
открывает файлы этого типа на рабочем столе. Примеры:

| Поле | Команда |
|---|---|
| Image | `gimp {file}`, `krita {file}`, `flatpak run org.gimp.GIMP {file}` |
| Text | `libreoffice --calc {file}` (CSV), `code --wait {file}`, `kate {file}` |
| Model | `blender --python-expr "import bpy; bpy.ops.doctor_toolkit.link_open(filepath=r'{file}')"` (нужно дополнение, §12.5) |

## 12.2 В редакторе

Над текстурой, таблицей строк, SimGroup/metamodel/variabledictionary,
скриптом Lua и моделью есть кнопка **Open in external editor** и выбор
формата:

| Ресурс | Форматы |
|---|---|
| текстура | PNG (первый слой) или DDS (все mip-уровни; для кубических и объёмных — только DDS) |
| таблица строк | CSV (столбцы `hash` и языки; Calc, Excel) или JSON (как `text-export`) |
| логика | JSON (как `logic-export`) |
| скрипт | Lua (декомпилированный текст) |
| модель | GLB (с материалами, текстурами и скелетом) |

Тулкит сохраняет ресурс во временный файл (так, как он выглядит в рабочем
пространстве, с вашими прежними правками), открывает его программой и
следит за файлом. Рядом с кнопкой появится **Linked: <файл>** и счётчик
импортированных сохранений, внизу окна — **Linked: N**: список открытых
файлов, **Unlink** (перестать следить; файл останется), **Reload file**
(записать в файл версию рабочего пространства, например после Ctrl+Z),
**Show folder**.

Что происходит при сохранении:

- импорт — обычная правка: просмотрщик обновляется, Ctrl+Z отменяет,
  **Apply to game** записывает в игру (в прямом режиме — сразу);
- **частые сохранения склеиваются**: сохранили десять раз за пару минут —
  в истории один шаг, Ctrl+Z возвращает состояние до первого сохранения.
  Если между сохранениями вы правили что-то ещё, следующее сохранение
  станет отдельным шагом;
- сохранение без изменений ничего не записывает;
- если файл не импортируется (ошибка в скрипте, сломанный JSON, файл ещё
  дописывается) — сообщение с причиной (для Lua — номер строки), слежение
  продолжается: исправьте и сохраните снова.

## 12.3 Из командной строки

```sh
# текстура в GIMP, пока не нажмёте Ctrl+C
doctor-toolkit edit "$GAME" gf2/frontend:tg4h:00000000.4802e0a7.f3d257db.9cf57f36 --with "gimp {file}"
# таблица строк: ПОТОК:НОМЕР ресурса, CSV, программа из настроек редактора
doctor-toolkit edit "$GAME" gf2/text/dd7d7050:0
# скрипт: только следить за файлом в своей папке, без запуска программы
doctor-toolkit edit "$GAME" КЛЮЧ --format lua --no-open --file-dir ./scripts
```

Ключи: `--with CMD`, `--format png|dds|csv|json|lua|glb`, `--file-dir`,
`--no-open`, `--wait` (закончить, когда программа закроется — для программ,
которые не уходят в фон), `--coalesce SECONDS` (окно склейки, 60),
`--direct`, `--workspace-dir`; для моделей `--new NAME` и `--retarget N`.
Ключ ресурса показывают поиск (`nav search`) и панель Details редактора.

## 12.4 Таблицы строк в CSV

Первая строка — `hash` и языки; дальше по строке на запись. Меняйте только
тексты: строки и столбцы можно переставлять, лишние строки удалять (они не
меняются), а новые хэши — нельзя (добавление строк появится позже).
Сохраняйте в UTF-8; разделитель — запятая, точка с запятой или табуляция.

## 12.5 Blender

Дополнение `doctor_toolkit` для Blender 4.2+ импортирует модели игры с
материалами, текстурами и скелетом и экспортирует их обратно в рабочее
пространство. Подробности — `docs/blender.md`.

**Установка.** Edit → Preferences → Get Extensions → ▾ → **Install from
Disk…** → `doctor_toolkit_blender-1.3.0-linux-x64.zip` из релиза (модуль
тулкита внутри). Если пакет без модуля — укажите в настройках дополнения
**Module folder** (§2 `docs/blender.md`).

**Работа.** 3D Viewport → N → вкладка **Doctor Toolkit**:

1. **Game** — папка игры, **Open game** (первый раз — около минуты).
2. Поиск по имени модели → выберите → **Import model**.
3. Правьте модель. Сохраняйте имена костей и материалов: по ним тулкит
   находит скелет и материалы игры. Не двигайте кости в режиме правки
   арматуры — игра всё равно использует свою позу.
4. **Check** — план импорта и предупреждения в панели, без записи.
   **Limit weights** оставляет у вершин не больше 4 весов костей (это
   делается и само).
5. **Export to workspace** — замена модели (**Replace**) или новый набор
   (**New model set**: имя и номера SimGroup, которые его покажут).
6. В редакторе тулкита — **Apply to game** или сборка мода.

Вместо шагов 1–2 можно открыть модель кнопкой **Open in external editor**
в редакторе тулкита (программа для моделей — Blender, §12.1) и сохранять
кнопкой **Save linked file** панели: каждое сохранение попадает в рабочее
пространство само.
