# 2. Первый запуск

## 2.1 Каталог игры

Каталог игры — папка, в которой лежат `godfather2.exe`, папка `gf2`, архивы
`GODFATH0.viv`–`GODFATH2.viv` и папки `mp_*`. Где её искать:

| Установка | Путь |
|---|---|
| Steam (Proton) | `~/.local/share/Steam/steamapps/common/The Godfather II` |
| Wine, диск | `~/.wine/drive_c/Program Files (x86)/EA Games/The Godfather II` |
| Lutris, Bottles | `<префикс>/drive_c/Program Files (x86)/EA Games/The Godfather II` |
| Копия игры | любая папка, где лежат перечисленные файлы |

Если указать не ту папку (например, папку выше или домашний каталог),
программа ответит, что это не каталог игры, и подскажет, какую выбрать.

### Автопоиск

Искать папку чаще всего не нужно: экран приветствия редактора показывает
список **Found on this computer** — все найденные копии игры с изданием и
тем, где они найдены (щелчок открывает игру, **Search again** — искать
снова, то же — Tools → Find installed games). В командной строке:

```sh
doctor-toolkit detect                  # все найденные копии
doctor-toolkit detect ~/Games/gf2      # проверить папку игры или префикс Wine
doctor-toolkit detect --json           # для скриптов
```

Где ищется (поиск только читает файлы и занимает доли секунды):

| Источник | Что читается |
|---|---|
| Steam (обычный, Flatpak, Snap) | `libraryfolders.vdf` → библиотеки → `appmanifest_24830.acf` (игра в Steam — приложение 24830) и папки `steamapps/common/*` |
| Proton | префиксы `steamapps/compatdata/*/pfx` |
| Ярлыки Steam для сторонних игр | `userdata/*/config/shortcuts.vdf` |
| Wine | `$WINEPREFIX`, `~/.wine`, `~/.local/share/wineprefixes/*`, `~/Games/*`, PlayOnLinux: реестр префикса (`system.reg`, `user.reg`: ключи `EA Games\The Godfather II`, `App Paths\godfather2.exe`, удаление программ) и папки `Program Files*/EA Games`, `Origin Games`, `Electronic Arts` — так находятся и установки Origin и EA app внутри префикса |
| Lutris | `~/.config/lutris/games/*.yml`, `~/.local/share/lutris/games/*.yml` (и Flatpak) |
| Heroic | `~/.config/heroic`: сторонние игры, GOG, префиксы игр |
| Bottles | `~/.local/share/bottles/bottles/*` (и Flatpak) |
| Windows | реестр (`EA Games`, `Electronic Arts`, удаление программ) и `Program Files` |

Каждая находка проверяется: в папке должны быть `godfather2.exe` и `gf2/` с
файлами игры. Одна и та же папка, найденная несколькими путями, показывается
один раз.

### Издание игры

Издание определяется по `godfather2.exe` (размер, SHA-256, версия, дата
сборки, разделы защиты от копирования), по включённым языкам
(`text/localetable.txt`) и по дополнениям в папке (загрузчик ASI
`dinput8.dll` со скриптами, папка старого тулкита). Его показывают
`detect`, строка состояния при открытии игры, Help → About и подсказка над
путём к игре. Известные издания:

| Издание | Версия | Сборка | Особенности |
|---|---|---|---|
| PC, цифровое | 1.0.789.0 | 2009-10-05 | без защиты от копирования; на нём проверен весь тулкит |
| PC, розничный DVD | 1.0.764.0 | 2009-01-27 | SecuROM; форматы на нём не проверялись |

Неизвестное издание показывается версией и датой сборки (`unknown build
1.0.766.0 of 2009-02-13`). Моды помнят издание, для которого сделаны: при
установке мода, сделанного на другом издании, менеджер модов предупреждает
(«the mod was made for another edition of the game …»).

Совет: для первых опытов сделайте копию игры (`cp -r`) и работайте с ней.
Тулкит и так хранит оригиналы, но копию не жалко.

## 2.2 Редактор

```sh
doctor-toolkit-gui "/путь/к/The Godfather II"
```

или запустите без аргументов и нажмите **Open game…** (Ctrl+O) на экране
приветствия или в меню File. В следующий раз редактор без аргументов
откроет последнюю игру с теми же вкладками; недавние игры — в File → Recent
games и на экране приветствия. При первом открытии строится **индекс игры** — имена и связи всех 212 544 ресурсов. Это
занимает от десятков секунд до пары минут; ход виден в строке состояния.
Индекс сохраняется в `~/.cache/doctor-toolkit/`, следующие открытия быстрые:
перечитываются только изменённые потоки.

Сразу открыть поток: `doctor-toolkit-gui "$GAME" gf2/frontend`.

Как устроено окно (вкладки, панели, палитра команд Ctrl+Shift+P, клавиши,
настройки) — раздел [10](10-interface.md).

## 2.3 Командная строка

Дальше в примерах `GAME` — путь к игре:

```sh
GAME="/путь/к/The Godfather II"
doctor-toolkit types "$GAME"               # какие типы ресурсов есть в игре
doctor-toolkit validate "$GAME"            # все ли потоки и TOC читаются
doctor-toolkit list "$GAME/gf2/frontend.str" --type tg4h
doctor-toolkit search "$GAME" rust         # поиск по всей игре
```

`doctor-toolkit help <команда>` и `doctor-toolkit <команда> --help` описывают
каждую команду. Все команды принимают пути с пробелами — заключайте их в
кавычки.

## 2.4 Первое открытие игры: снимок оригиналов

При первом открытии игры редактор проверяет её файлы (в фоне, без чтения
всей игры) и предлагает одно из двух.

**Игра не изменена** (нет резервных копий тулкита, нет изменений старого
тулкита, нет эталона): «Save the fingerprints of the original files?».
**Save fingerprints** сохраняет размер и SHA-256 всех потоков и таблиц
содержимого в `_doctor_toolkit/reference.json` — это `doctor-toolkit
integrity "$GAME" --save-reference`. Хэширование читает всю игру один раз
(около 9 ГБ), ход виден в строке состояния. Потом **Check game files** и
`integrity --full` точно скажут, какие файлы отличаются от оригиналов.

**Игру изменил старый тулкит** (в папке `_toolkit` есть его копии, и файлы
игры от них отличаются): окно перечисляет его патчи и число изменённых
файлов и предлагает:

| Кнопка | Что делает | Командой |
|---|---|---|
| Take over its patches as mods | копии старого тулкита становятся оригиналами, его патчи ставятся модами (окно Mods); файлы игры не меняются | `doctor-toolkit mods import-old "$GAME"` |
| Restore the original files | копии становятся оригиналами и возвращаются в игру: изменений старого тулкита больше нет | `doctor-toolkit integrity "$GAME" --adopt-old-backups`, затем `doctor-toolkit restore "$GAME"` |
| Not now | спросить при следующем открытии | — |
| Don't ask for this game | больше не спрашивать (настройка `skip_first_run` игры) | — |

Если тулкит уже работал с игрой (есть `_doctor_toolkit/backups`) или эталон
сохранён, ничего не предлагается. Проверить игру можно в любой момент:

```sh
doctor-toolkit integrity "$GAME"
```

Подробнее — в разделе [8](08-integrity.md). Запуск игры из редактора —
раздел [11](11-play.md).
