# Этап 76: Сохранения

- Состояние: сделан (2026-11-16), часть блоков не разобрана.
- Зависит от: [этап 72](stage-72.md).
- Целевое издание: только PC 1.0.789.0.

## Что сделано

- Формат файла: заголовки `RGMH` и `NMSD`, контейнер с тремя суммами CRC-32, блок сведений, блок данных из 25 блоков объектов — [описание](../../formats/save.md), [система](../systems/saves.md), [адреса](../exe/saves.md).
- Как игра пишет и читает блоки: общий список сохраняемых объектов, пропуск неизвестных блоков.
- Разобраны блоки: переменные сюжета, деньги и семья игрока, семьи, здания, города, игрок, журнал, чекпоинт, убежища, оружие.
- Переменные: сохраняются переменные вида 1 из загруженных словарей по хэшу записи; своя переменная мода и удаление мода — [опыт на стенде](../experiments/save-mod-variable.md).
- Просмотр: `doctor-toolkit save` (сводка, блоки, JSON, имена из файлов игры) и окно редактора «Посмотреть сохранение…»; только чтение.
- Проверка на 14 сохранениях: тест `crates/doctor-toolkit/tests/saves.rs` (`EARS_GF2_SAVES`).
