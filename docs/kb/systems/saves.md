# Сохранения

Сохранение — файл постоянного размера с заголовком, тремя контрольными суммами и 25 блоками: по блоку на объект игры, который умеет себя сохранять. Формат контейнера разобран полностью, содержимое блоков — для главных систем. Тулкит сохранения только читает: `doctor-toolkit save`, окно редактора «Посмотреть сохранение…».

## Что известно

- Файлы `GF2-EN-autosave` и `GF2-EN-<цифры>` лежат в `Documents/EA Games/<название игры>/<номер профиля>`; при старте `-stream` — прямо в папке игры в документах. Размер всегда 272 740 байт.
- Состав: заголовок `RGMH` (профиль, город, время игры), имя `NMSD`, контейнер с суммами CRC-32 (`0x00D373D0`), блок сведений и блок данных 0x40000 байт (см. [формат](../../formats/save.md) §1).
- Объект регистрируется в списке `*0x0122341C` с идентификатором блока; при загрузке блок без объекта пропускается, объект без блока остаётся с состоянием по умолчанию ([адреса](../exe/saves.md)).
- Переменные сюжета: сохраняются переменные вида 1 из загруженных словарей `variabledictionary`, ключ — хэш записи словаря; в обычной игре их 59 из 63 (см. [сюжет](story.md)).
- Деньги игрока — число f32 в блоке `player-family`; там же записи заслуг людей чести: 12 счётчиков и оружейная лицензия 1–4 (число, которое раньше читалось как «1, 2 и 4»), и флаг дополнения. У семьи `corleone` в блоке `families` вместо денег константа −1 000 000.
- Запись члена семьи в блоке `families` (0x50 байт) хранит место в древе семьи игрока, ранг, специальности и GUID оружия; в заголовке блока — уровень древа 0…8 (см. [команду](crew.md)).
- Блок `families` — шесть семей стратегической игры: деньги, флаги, здания, отношения, члены. Блок `buildings` — 113 зданий: владелец, состояние, охрана. Блок `inventory` — 11 ячеек оружия с патронами. Блок `cities` — состояние трёх городов.
- Места игрока в сохранении нет: блок `checkpoint` хранит номер чекпоинта и матрицу точки возврата, найденной по месту игрока, — поэтому после загрузки игрок всегда в одной точке ([вопрос](../questions/save-player-position.md)).
- Свою сохраняемую переменную мод заводит записью вида 1 в словаре; после удаления мода её пара при загрузке пропускается ([опыт](../experiments/save-mod-variable.md)).
- Сохранение помнит бит «включено» потока (`EnableDisableStreams`) и грузится без мода, с которым сделано ([опыт](../experiments/saves-with-stream-start.md)).
- В меню паузы Save — пятый пункт; с сохранением в главном меню выделен Resume Game ([опыт](../experiments/save-after-prologue.md)).

## Что неизвестно

- Содержимое 14 блоков из 25 и часть полей разобранных: [вопрос](../questions/save-undecoded-chunks.md).
- Когда срабатывает автосохранение: [вопрос](../questions/autosave-trigger.md).
- Файл `profiles.dat` и запись сохранений тулкитом — не делались.
