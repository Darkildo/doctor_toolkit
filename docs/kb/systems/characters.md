# Персонажи

Персонаж собирается из частей по базе `partsdb`; цвета одежды, кожи и волос приходят заменами материалов; внешность игрока и его людей задаёт редактор `mobface`.

## Что известно

- База (`partsdb`) описывает группу персонажей; набор — один тип персонажа (`wrk_0001`, `_all` у игрока). Основной поток — `gf2/globalfolder/characters/allcharacters`; все 1 194 набора персонажей собираются.
- Сборка: в каждом слоте набора берётся один вариант (игра — случайно) — список частей; часть хранит id ресурсов `mesh` (слот 0 — `_lod1`, слот 1 — `_lod2`).
- Теги: часть с тегом скрывается, если тег «поставлен» (`untuckedShirtCulled` — ремень скрыт, `hatCulled` — волосы скрыты); в игре это делают меню `mobface`.
- Внешность: выбор пресета набора даёт список замен материалов «материал меша → материал вместо него» и, возможно, блендер; для отдельных частей набор задаёт кандидатов материала (`stripe_dress` → 10 расцветок).
- Морфы: блендер — веса морф-целей `fat`, `skinny`, `muscular`, `scrawny` и 32 лицевых (`headnawd`, `eyesize`, …); хэш морф-цели — SDBM имени.
- Материалы одежды по умолчанию отладочные (`g_TintColor0..2` = красный, зелёный, синий): основная текстура — маска оттенков (`gf_char_tint_mask_*`, 2 488 материалов в `allcharacters`); настоящие цвета приходят заменами пресетов. Игра возводит цвета в степень 2.2 при загрузке материала (`0x009DA3B0`).
- Кожа и глаза — `g_SkinTintColor`, `g_EyeTintColor`; у NPC цвета «зашиты» в материалы — новых цветов без новых материалов не получить.
- `mobface` — один ресурс в `globals_global` (`FboM`, версия 9): 13 палитр (`mobfaceshirts`, `tintskin`, `tinthair`, `tinteyes`, …), 16 ползунков лица, 11 разделов меню.
- В SimGroup: `PartedAnimated` атрибут 2 — набор (`lwd_0165_business`, `crosato_0001_main`), 0 и 1 — пресет и элемент; `Animated` 2 — id рига; шаблон NPC — `SimNpc` (атрибут 1 → `CommonNPC`) в `globals_global`.
- Проверено в игре: новая одежда и цвета на NPC; шляпа `a_hat_fedora` и новая часть `doctor_jacket` на игроке при старте `-stream`.
- Анимации — банки `bnk` скелета человека (2 751 ресурс), см. [анимация](../engine/animation.md).

## Что неизвестно

- Функция id мешей (SDBM строки с неизвестным префиксом).
- Пункты меню `mobface` и связь «пункт → теги и параметры».
- Кто ставит теги скрытия у NPC (вероятно, части с определёнными именами).
- Почему в проверке не появился капо `crosato_0051`.
