# Диалоги F2F и речь

Разговор лицом к лицу (F2F) — дерево `dlg` в отдельном потоке; что именно скажет актёр, решают события речи его `chv`; звук и субтитр реплики лежат в файле речи архива `.viv`.

## Что известно

- Диалог — ресурс `dlg` в потоке `gf2/globalfolder/dlg/<хэш>` (143 потока, в каждом ещё банки `bnk` с клипами `f2f_*`). Имя потока — хэш.
- Кто начинает разговор — строковый атрибут SimGroup с путём потока: `NPC` 5 у объектов `CommonNPC` (3431 место), `ChangeNPCSettings` 27 (112), `ChangeDialog` 3 (13). 107 разных путей; у 36 диалогов пользователей в SimGroup нет.
- Загрузчик `dlg` — `0x006FB320`, версия 4; файл — образ памяти со смещениями вместо указателей.
- Виды узлов в файлах игры: 1 — реплика (931), 2 — условие `==` (364), 0x20 — флаг NPC (235), 0x21 — флаг NPC B (7), 0x22 — выбор (122; 2, 4 или 5 ветвей), 0x23 — конец (143, ровно один на файл), 0x24 — присваивание (461). Виды 3, 4, 5 — `!=`, `<`, `>`.
- Реплика: слово 0 — говорящий (1 — игрок, 2 — NPC), слово 8 — хэш события речи `sdbm(lower(имя))` (`P2_LINE1`, `F2F_ENJOY_FLIGHT`), слова 9, 10, 12 — группы клипов.
- Выбор: слово 0 — время на ответ, с (600, 10, 6; −1 — без ограничения); до 5 вариантов, подписи — строки `lh2` по имени (`hud_csa_f2f_choicea`).
- `chv` (259 ресурсов, загрузчик `0x006F4840`, версия 3) — события речи персонажа: строка по 32 байта (id звука, id субтитра, вес 1–3), выбор строки случайный по весу. На `chv` ссылается [ChatterComponent](../classes/ChatterComponent.md) атрибутами 0..3.
- `smb` (59 ресурсов, 12 918 записей) переводит 128-битный id звука в имя файла (`d_mob3_xxx_0001806.exa`) и параметры; путь `audiostreams\<папка>\<имя>.snu` игра строит из имени (`0x004A8580`); вторая озвучка — `audiostreams\es\…`.
- Какой набор говорит: событие ищется в четырёх слотах `ChatterComponent` говорящего в порядке 3, 2, 1, 0 (`0x006F3B80`); [SimpleChatterBox](../classes/SimpleChatterBox.md) говорит событие по сообщению и может дать свой набор.
- Новая реплика с новым событием делается одной операцией (`voice-add`, мастер редактора, мод формата 4) и проверена в игре — [опыт](../experiments/new-voice-line.md).
- Текст реплик — не в `lh2`: субтитр лежит в метаданных файла `.snu`, кусок `0x3596A436` — таблица `LCH2` с восемью столбцами `EN CS NL PL RU ES SS LL`.
- `get` (один ресурс в `globals_global`, 1372 записи по 36 байт) — таблица событий речи по хэшу имени: пауза повтора, ранг, флаги с группами, приоритет. Событие без записи не говорится, а воспроизведение читает запись без проверки (`0x006F5530`).
- Выход 3 `ChangeNPCSettings` — конец разговора лицом к лицу с этим NPC (`…_f2f_success`, `…_dialog_done`).
- Проверено в игре: диалог с Майклом на террасе идёт с субтитрами, правка субтитра `subtitle … --set en=…` видна.

## Что неизвестно

- Названия «переменных» условий (номера запросов `0x006EBFF0`) и слов 1–4 выбора.
- Редактор диалогов не применяет правило слотов: [какой `chv` говорит реплику](../questions/dialogue-which-chv-speaks.md).
- [Реплика персонажа в мире и реплика узла диалога с новым событием](../questions/voice-line-of-a-character.md) на стенде не проверены.
- [Смысл части полей `smb` и `get`](../questions/speech-bank-and-event-fields.md).
- Кусок `0x30B00ADF` файла речи (гипотеза — данные для губ); исходные имена диалогов.
