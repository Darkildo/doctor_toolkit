# Своя переменная мода в сохранении и загрузка без мода

Проверяли: попадает ли в сохранение переменная, которую мод добавил в `variabledictionary`, и что происходит с таким сохранением в игре без мода.

Как: в теневой копии в словарь `gf2/cuba` добавлены `s76_mod_saved` (хэш записи `76760001`, вид 1, значение 76) и `s76_mod_plain` (`76760002`, вид 0). Старт `-stream gf2 cuba`, меню паузы → Save; затем это сохранение загружено из главного меню в тени без мода и сохранено ещё раз. Файлы читались командой `doctor-toolkit save`.

| Шаг | Результат |
|---|---|
| сохранение с модом | 47 переменных: 46 игры и `76760001 = 76`; `76760002` нет |
| загрузка без мода | загрузилось, падений нет, игрок в Гаване у ворот аэропорта |
| повторное сохранение без мода | 59 переменных, `76760001` нет; исходный файл не изменился |

Что из этого следует:

- Сохраняемая переменная мода — запись вида 1 в словаре; ключ в сохранении — хэш записи, поэтому его нельзя менять между версиями мода.
- Удаление мода сохранение не ломает: пара неизвестной переменной пропускается и при следующем сохранении пропадает.

Не проверено: что значение возвращается в игру при загрузке с модом (по коду `0x004425A0` — да); словарь в потоке, которого нет в памяти в момент загрузки сохранения.
