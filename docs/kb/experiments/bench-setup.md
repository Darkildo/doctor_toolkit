# Устройство стенда проверки в игре

Стенд (`tools/game-bench.sh`, помощник `tools/hidden-parent.py`) запускает игру под Wine на теневой
копии каталога игры, ведёт её по меню и снимает экран. Экран и ввод пользователя не задействованы,
файлы игры не меняются.

- **Скрытый X-сервер.** `Xephyr -parent <окно>`: окно-родитель создаёт `hidden-parent.py` и никогда
  не отображает. Номер дисплея выбирается через `-displayfd`. `SERVER=xvfb` — Xvfb вместо Xephyr
  (окна на хозяине нет вовсе). `VISIBLE=1` показывает окно для отладки.
- **Графика.** По умолчанию программная: Mesa llvmpipe, D3D9 игры — wined3d. `DXVK=1` кладёт
  `d3d9.dll` DXVK в тень на время прогона и добавляет `d3d9=n,b` в `WINEDLLOVERRIDES`.
- **Теневой каталог** (`shadow ИГРА ТЕНЬ [ОТН_ПУТЬ...]`): каталоги настоящие; `.str`, `.viv`, `.vp6`,
  `.vpat` и файлы больше 16 МБ — символические ссылки (2371); остальное копируется (1380 файлов,
  84 МБ); перечисленные пути копируются до правки; хэши sha256 оригиналов — в
  `ТЕНЬ/.game-bench/originals.sha256`. `verify` сверяет хэши оригиналов.
- **Префикс.** Отдельная копия базового префикса (588 МБ): ссылки из `drive_c` наружу заменены
  пустыми каталогами, `HOME=ПРЕФИКС/bench-home` с каталогами XDG внутри, звук выключен, адаптер
  NVIDIA в реестре (`VideoPciVendorID=0x10de`, `VideoPciDeviceID=0x0402`, `VideoMemorySize=1024`),
  виртуальный рабочий стол Wine размером с экран.
- **Ввод.** Курсор меню игра ведёт по относительным движениям: щелчок в точку — движение в `0,0`,
  затем в `центр + (x, y) / CURSOR_GAIN`, затем нажатие. Клавиша удерживается `HOLD` = 0,4 с.
  Главное меню принимает только клавиши.
- **Сценарии.** `run` — по секундам (`KEYS`, `CLICKS`, `SHOTS`, `DURATION`); `play ТЕНЬ OUT СЦЕНАРИЙ`
  — шаги по экрану (`shot`, `key`, `hold`, `click`, `await ИМЯ`, `seek ИМЯ КЛАВИША`, `walk`, `pos`);
  `start`/`do`/`stop` — сеанс, шаги вживую. Эталон экрана — участок в оттенках серого, совпадение —
  средняя разница яркости не больше 12 из 255.
- **Быстрый вход.** `GAME_OPTIONS="-stream gf2 cuba"` пишет `ТЕНЬ/cmd.txt` на прогон: игра сразу в
  уровне, сохранения и профиль не нужны.
- **Память игры.** `MEMORY=1`: игра — дочерний процесс `tools/bench/gamemem.py serve`, шаги `find`,
  `track`, `pos`, `walk` читают матрицы игрока.
- **Запись звука.** `AUDIO_CAPTURE=1` включает драйвер `alsa` и свою конфигурацию ALSA: звук пишется
  в `OUT/audio.wav` (48 кГц, стерео, 32 бит), на звуковую карту не уходит. Время в записи растянуто;
  звук опознаётся по спектру (`tools/bench/audio_tones.py`) или корреляцией (`audio_match.py`).
- **Журналы.** `OUT`: `shot_NN_TTTs.png`, `timeline.txt`, `wine.log`; `TRACE_FILES=1` — `strace`
  открытий файлов в `OUT/files.trace`.
