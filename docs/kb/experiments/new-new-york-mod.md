# Мод «Новый Нью-Йорк»: десять прогонов на стенде (этап 60)

Тестовый мод (исходник вне репозитория) собран скриптом через MCP: остров, мосты, бойцы семьи Кармине.
Игра в каждом прогоне — сразу в Нью-Йорке (`-stream gf2 queens` подменой), рабочее пространство
отдаётся подменами (`--apply --workspace-dir W`), в последнем прогоне — `--mods`.

| Прогон | Итог |
|---|---|
| 1 | `stream_load` грузит поток за 10 кадров; всё стоит боком — `add_object` сохранил поворот образца (−90°) |
| 2 | `ZoneStreamEnable` новый поток не грузит; `send_message nny_point_on` — загружен ([заметка](zone-stream-enable-new-stream.md)) |
| 3 | `TriggerAuto` + `EnableDisableStreams`: поток загружен через 25 с после старта без вызовов связи; 23 бойца с гербом семьи Кармине; ворота — 33; капо `crosato_0051` не появился |
| 4–5 | мост перенесён с X −395 на X −385 (ось закрыта контейнерами); проход с дока на остров без переносов: ступни 6,40 → 7,70 (горб) → 6,79 → 6,42; 721 с без исключений |
| 6 | игрок сел в полицейскую машину (`e`), машина едет по доку; машина на острове провалилась по крышу — материал коллизии от дерева |
| 7 | материал улиц (поверхность 18): машина стоит на острове (6,37 м); `nny_boss_down` вручную — «Rosato Point is clear» |
| 8–9 | остров на мини-карте; после `nny_alarm` бойцы бегут к игроку и стреляют |
| 10 | мод из файла через менеджер модов (`live install --mods`, 18 подменённых файлов): проход по северному и восточному мостам, волны 23 → 34 → 42; 736 с без исключений; `verify`: оригиналы не менялись (27 файлов) |

Что из этого следует:

- Материал коллизии решает, держит ли она машину: поверхность 11 (от образца-дерева) — игрок ходит,
  машина проваливается; поверхность 18 (земля дока) — машина стоит.
- Высоты мерились только ходьбой: после `teleport` выше 0,5 м над землёй игрок остаётся на высоте
  переноса; `player` даёт точку ≈1,9 м выше ступней.
- Под эстакадой у X ≈ −269 мост не проходит: игрок упирается в стену-опору.

Что не проверено на этапе 60: смерть босса в бою, проезд машины по мосту, машинный трафик на острове
(графа машин нет). Первые два проверены на этапе 63 — [мод для игроков](new-new-york-players.md).
