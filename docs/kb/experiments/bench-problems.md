# Найденные проблемы стенда и их решения

Что мешало прогонам и как это обойдено.

| Симптом | Причина | Решение |
|---|---|---|
| окно «Your Graphics Card does not meet … minimum requirements» | под llvmpipe wined3d сообщает программный адаптер | адаптер NVIDIA в реестре префикса |
| то же на голом X-сервере без виртуального рабочего стола (вкладка «Игра») | — | `explorer /desktop=doctor_toolkit,ШxВ` перед `godfather2.exe` |
| «Unable to find your profile, please try again» | Wine под `LC_ALL=C` не может создать папку с `™` в имени | стенд меняет только `LC_NUMERIC` |
| профили стенда попали бы в `~/Документы` | ссылки папок пользователя в префиксе; папку профиля Wine создаёт ссылкой на каталог XDG | каталоги внутри префикса, `HOME=ПРЕФИКС/bench-home` |
| щелчки `xdotool` не попадают в меню | курсор игры относительный | режим `relative` |
| первый запуск на новом префиксе: окно о видеокарте, выход через 7,6 с или чёрный экран | не установлена; вероятно, гонка с регистрацией адаптера | прогрев рабочего стола (`wine cmd /c exit`), при `status: exited` — повтор |
| падение игры не останавливает сценарий | Wine показывает окно отладчика, процесс жив | `await` проверяет `wine.log` на `Unhandled … starting debugger` |
| под нагрузкой игра пропускает нажатия | 1–2 кадра/с, ввод опрашивается раз в кадр | `seek !ИМЯ` повторяет нажатие; в меню паузы держать 0,7 с |
| одно нажатие `Down` в главном меню сдвигает на два пункта | удержание 0,4 с игра видит как повтор | `seek` (`TAP` = 0,15 с) или `HOLD=0.15` |
| одинаковый `hold` даёт разный путь (0,06 м и 0,9 м) | темп игры на llvmpipe следует частоте кадров | `walk` по положению из памяти |
| `play` и менеджер модов видят любой `godfather2.exe` на машине | слежение по имени процесса | на стенде `DOCTOR_TOOLKIT_GAME_PROCESS=no-such-game.exe` |
| консоль «GF2SE» скрипт-хука GF2ASI уводит фокус, уровень не грузится | окно игры свёрнуто | щелчок по кнопке игры на панели задач Wine (`CLICK_MODE=absolute do OUT click 140,758`) или GF2ASI в тени выключен |
| «Установить мод…» менеджера открылось на основном рабочем столе | `rfd` 0.18 идёт через `xdg-desktop-portal` | менеджер только под `dbus-run-session` |
| стенд с `SERVER=xvfb` требовал основной дисплей | — | исправлено: Xvfb запускается без `DISPLAY`/`WAYLAND_DISPLAY` |
| `winedbg` к игре стенда не подключается (`error 5`) | — | место зависания искали по журналу модуля |

Игра, запущенная во вкладке редактора, пережила его закрытие (Xvfb и игра работали невидимо
26 минут); теперь сервер вкладки запускается с `PR_SET_PDEATHSIG`.
