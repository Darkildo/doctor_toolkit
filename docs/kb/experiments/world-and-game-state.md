# Мир и состояние игры вживую (этап 48)

Быстрый стенд: `-stream gf2 cuba`, `DXVK=1`, `SERVER=xvfb`, модуль `live install --writes` (протокол 4,
проверка издания — 84 места).

| Проверка | Результат |
|---|---|
| чтение | `live time` — 16:04, день 0 года 1950, 60 с/с; `live weather` — `WeatherManager` нет (`*0x0112AFF4 = 0`); `live money` — 0; `live family` — 7 закрытых мест (3, 3, 3, 3, 4, 4, 5), 28 семей; `live mission` — текущего чекпоинта нет, 34 в потоках; 48 переменных |
| время суток | `23:30 --rate 0`: в следующем кадре ночь (тёмное небо, фонари и окна); через 70 с всё ещё 23:30:00; `12:00 --default-rate` — день, часы идут |
| деньги | `--add 12345` — счётчик `$12,345`; `--set 500` — `$500` |
| переменные сюжета | `Use_Surveys = 1` и `send check_should_use_surveys` — `VariableSwitch` шлёт `do_survey_message`, игра показывает окно «SURVEY: Please pause…»; с 0 — ничего; `Bridge_test` 0 → 7 |
| потоки по одному | выгрузка `yuri/high/filler_056_01` (1 кадр) — исчезают балконы и решётки жёлтого дома; загрузка (3–38 кадров) — вернулись; второй запрос сразу — «not loaded yet … one request at a time»; выгрузка потока игры без `--force` — отказ |
| 10 минут | 610 с: 55 из 55 ответов, 18 циклов; в конце `$1,800` (18 × 100), игрок ходит; исключений нет; `verify`: оригиналы не менялись (27 файлов) |

Найдено:

- Для имени потока, которого нет, игра заводит запись в состоянии 1 («запрошен») и держит её
  навсегда. Модуль не запрашивает поток без файла в папке игры; запрос, не выполненный за 120 с,
  перестаёт держать очередь.
- Дождь в одиночной игре не появляется: `WeatherManager` есть в коде, но ни одна SimGroup его не
  создаёт; небо меняют ключи времени суток.
- Загрузка зоны `high` идёт быстро (несколько кадров при DXVK).
