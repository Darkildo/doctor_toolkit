# Новая голосовая реплика с новым событием звучит в игре

Проверяли всё звено новой реплики: событие в `chv` и `get`, запись `smb`, файл в накладном архиве, субтитр.

- Как: `voice-add` — тон 2468 Гц, 3 с, событие `DOCTOR_TEST` в наборе речи Доминика; запуск — копия [SimpleChatterBox](../classes/SimpleChatterBox.md) в `gf2/cuba/local` (сообщение `doctor_say`, набор речи в атрибуте 7, говорящего нет); стенд с записью звука, сообщение из живой связи.
- Рабочее пространство: четыре сообщения — тон четыре раза по 3 с (доля энергии 0,79–0,81, между ними 0,00), игра не падает.
- Мод (формат 4, чистая тень, менеджер модов): три сообщения — тон три раза.
- Профиль с включёнными субтитрами: в кадре «Doctor toolkit test line.» — текст из метаданных нового файла.

Следует: новая реплика и новое событие работают; мод несёт звук. Не проверено: [реплика персонажа и узла диалога](../questions/voice-line-of-a-character.md).
