# Графический модуль: проверки на стенде (этап 59)

Стенд: `DXVK=1`, `SERVER=xvfb`, свой префикс и тень, модуль связи на порту 47859, старт подменой
`cmd.txt` (`-stream gf2 cuba`). `doctor_render.asi` и `doctor_render.cfg` кладутся в `scripts/` тени
перед каждым прогоном. Нагрузка машины 15–20 на 32 потока: абсолютные кадры/с — оценка.

| Прогоны | Окно | Что проверено |
|---|---|---|
| `V0`, `V1` | 640×480 | синхронизация игры (замок 30) против модуля: 30,0 → 58,1 к/с; темп 1,00, ходьба 6,07 / 5,88 м/с |
| `N0`, `T1` | 640×480 | без ограничения: 88 и 106 к/с, время суток 43,5 и 48,7 игровых с/с вместо 60 |
| `F30`, `F60`, `F120` | 640×480 | предел модуля: 30,05 к/с при 170 мс/с потока рендера; 60 и 120 упёрлись в загруженную машину (35–59 к/с); время суток 59,7–60,3 |
| `FT` | 1280×720 | трассировка 11 вызовов `SetFov` (`fov_trace=1`): картинку меняет только `0x00425FE4` |
| `FOV90`, `FOV75` | 1280×720 | вертикальный угол (`live camera`) 41,2° → 66,1° и 51,9°; 41,2° — камера на бегу (67,5° по горизонтали), в покое 36,0° — см. [вопрос](../questions/fov-run-camera-angle.md) |
| `P0`–`P3` | 1280×720 | без модуля, FXAA, резкость 60 %, оба: края сглажены, интерфейс читается; 23–28 к/с во всех |
| `D_none`, `D_dense`, `D_light` | 1280×720 | плотность `TrafficManager` ×2 и ×¼ — без разницы ([заметка](traffic-density-no-effect.md)) |
| `L0`, `L1` | 1280×720, Нью-Йорк | `play --render` и `play --laa --low-memory 256` ([память и LAA](memory-and-laa.md)) |

Найдено:

- Первый прогон FXAA упал в `0x0042138B` на 3-й секунде загрузки (гонка запуска с `-stream`); повтор и
  все остальные прогоны (21) — без падений.
- Методы камеры игрока `0x009BD990`, `0x009BDC40`, `0x009BE4B0`, `0x009BEB00` пешком не вызываются;
  угол вида задаёт менеджер камер.
- Ролики расширяются тем же множителем угла ([ролик igc16](cutscene-igc16-subtitle-fov.md)).
- После всех прогонов `verify` — оригиналы не менялись.

Что не сделано и не проверено: FSR 1; режим во весь экран; постэффекты на Windows (`CreateStateBlock`
на `PUREDEVICE` может отказать — в источнике гипотеза); HUD проходит через фильтр.
