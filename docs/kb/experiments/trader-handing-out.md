# Выдача из логики и торговец с меню на стенде (этап 75)

Гавана (`-stream gf2 cuba`), пять сеансов; объекты опытов — копии объектов игры в `gf2/cuba/local`, деньги читались `live money`, оружие — по счётчику на экране.

- **Оружие и патроны.** `GiveItemRelay` с целью-игроком: пистолет 8-8; повторная выдача с флагом 4 — 8-16, 8-24 (предел `Gun.8`). Без флага 4 второй раз ничего не выдаётся.
- **Уровень оружия.** Пистолет ур. 2 с флагом 4 заменил ур. 1: «Silenced Pistol (lvl. 2)» 7-28.
- **Своё оружие.** Копия автомата с `Gun.7` = 13, `Gun.8` = 91 — «13-78»; копия с новым именем `Item.0` — без значка и названия.
- **Деньги.** Предмет «Cash» через реле: +100 в книгу 4. `MoneyAdaptor` по `live send` (нет данных) — ничего; от входа в объём — списал; через «счёт» (предмет «Cash» с нулевой суммой и сообщением подбора) — −300 за покупку, в том числе по `SendMessage` из Lua.
- **Объём.** Выключенный объём, включённый сообщением при игроке внутри, срабатывает сразу и повторяется каждые ~0,2 с.
- **Свой персонаж и диалог.** Второй `SpawnPoint` с `SimNpc` кассира Майами дал у ворот аэропорта «Dolores Rush»; новый поток диалога грузится по пути из `ChangeNPCSettings.27`.
- **Меню.** Мод примера `examples/trader`, поставленный менеджером модов: подсказка «E Talk», меню из четырёх своих подписей (вариант 0 слева, 1 справа, 2 снизу, 4 сверху). Без «переменных» `0x49` и `0x30` в начале дерева меню не появляется.
- **Не получилось.** Выбрать вариант в меню ни одной клавишей и мышью — [вопрос](../questions/f2f-choice-input-on-bench.md); покупки проверены сообщениями мода (5000 → 4700 → 4500 → 3000, автомат в руке). Лечение аптечкой и метательное оружие не увидены: ранить игрока на стенде не вышло, сохранение не снято.
