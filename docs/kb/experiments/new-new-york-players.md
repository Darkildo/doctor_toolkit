# Мод «Новый Нью-Йорк» для игроков: менеджер модов, босс, машины (этап 63)

Open Mod Manager — на своём Xvfb 1600×900 под `dbus-run-session`, щелчки `xdotool`; игра — `wine
godfather2.exe` в префиксе стенда.

| Проверка | Результат |
|---|---|
| установка 1.0 и обновление на 1.1 | вопрос «Установить 1 мод?» → карточка «Ещё не записан в игру»; 1.1 поверх — «обновлён (была версия 1.0)»; файлы тени при установке не меняются |
| «Играть с модами» | игра через 8 с в Нью-Йорке; модуль подменяет 17 файлов (открыто 6); после выхода «Игра закрыта. Её файлы не менялись»; тень совпала побайтно (3 753 записи) |
| «Записать в игру» → «Вернуть оригиналы» | пересобрано 12 потоков, заменено 17 файлов; после возврата `integrity` — 19 исходных, 0 изменённых; `verify` — оригиналы не менялись |
| смерть босса | в 1.0 зачистки нет: `ChangeNPCSettings.3` — конец разговора с NPC (во всех 175 объектах игры), не смерть. Смерть сообщает `StandardDamageComponent.5` у `CommonNPC`. В 1.1 босс — своя копия `CommonNPC` (`.5 = nny_boss_down`) и `SimNpc`: после смерти — «Rosato Point is clear» |
| метка мини-карты | снимается атрибутом 11 `UIHudMiniMapMarker` (в 1.0 был 10 — метка оставалась) |
| Миссия 10 на доке | объём тревоги острова в 1.0 доходил до z −100 и накрывал объекты чекпоинта 825; в 1.1 начинается с z −70: на доке у поста тревоги нет (3 NPC в 120 м), на мосту — есть (18) |
| машина по мостам | полицейская машина мода, автопилот по точкам: северный мост 6,40 → 7,70 → 6,40; восточный 6,39 → 7,68 → дамба 6,17–6,30; у спуска на дамбу (x ≈ −294) машина дважды цеплялась |

Отдельные заметки: [сохранения](saves-with-stream-start.md), [оружие](weapon-in-hand.md),
[падение при старте Миссии 3](game-crashes.md).

Что не проверено: перетаскивание файла в окно и диалог «Установить мод…» (на стенде нет источника
XDND, диалог идёт через портал), проход сюжетных миссий дальше старта, полное здоровье босса в бою
(здоровье снижено в тестовой копии до 150). Машины мода есть не во всех запусках.
