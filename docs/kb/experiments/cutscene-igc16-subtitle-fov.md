# Ролик igc16: субтитр, фокусное расстояние и угол обзора

Третья волна проверок (2026-11-14). Игрок перенесён к дворцу (−262; 6; −3), папочный поток
`…/cp_734/_734_igc_content` загружен `live stream load`, ролик — `live send start_igc_16`;
`live camera` и снимок каждые ~0,18 с. Субтитры включены один раз в меню паузы и остались включены в
следующих запусках того же префикса.

- **Субтитр: текст и время.** Строка 0 — текст правкой `lh2` папочного потока
  (`text-export`/`text-import`), время `cutscene subtitle --line 0 --start 1000 --duration 3000` (было
  5,064 с, 3,328 с). На снимках с 6-го по 22-й (≈1,0–3,9 с) — «DOCTOR TOOLKIT: subtitle edited,
  line 0.», с 23-го — нет.
- **Фокусное расстояние (`0x307`).** Кадр `s02` 50 → 25 мм (`cutscene export`/`import`): `live camera`
  — 68,2° (расчёт `2·atan(16,93/25)` = 68,2°); без правки — 37,4°. Кадр `s01` без правки — 27,2°
  (70 мм).
- **Угол обзора графического модуля в роликах.** С `fov=90`: `s01` 27,2° → 45,5°, `s02` 68,2° → 99,1°
  (отношение тангенсов 1,733 при множителе 1,732); в игре 36,0° → 58,7°. Ролики расширяются тем же
  множителем, что и игра: менеджер камер общий.
- Во время ролика трассировка видит лишний вызов `SetFov` из `0x0044CD4F` (11 раз, 42°).

Что из этого следует: справка `--fov` («cut-scenes keep theirs») была неверна и исправлена. Признака
«идёт ролик», по которому модуль мог бы оставить угол ролика, пока не найдено.
