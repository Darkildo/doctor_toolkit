# Граф анимации: правка узла видна на игроке

Третья волна проверок. Вход `idle` банка `gf2/globals_global:bnk:c0e2841d`: последовательность — два
клипа `588faa9b` (по 180 тиков), затем случайный выбор: `idle` (1110 тиков, вес 4) или вариации
(вес 2).

Правка `anim graph --set`: узел 13 — клип 270 `ambient_wrist_check_time`, длительность 278, вес 100.

Стоящий игрок без ввода, снимок каждые ~1,4 с:

- с правкой — рука к часам на снимках 4–5 и 12–13 (цикл ≈10,6 с = 2 × 3 с + 4,6 с);
- без правки (30 снимков, 40 с) — одна вариация в начале, дальше неподвижная стойка.

Вывод: правленый граф анимации игра принимает; выбор клипа и его вес работают как записано.
