# Падения игры, найденные на стенде

Сводка падений и зависаний, которые дали опыты, с причиной там, где она названа в источнике.

| Адрес | Когда | Причина | Этап |
|---|---|---|---|
| `00BAADFA` (запись) | через 1,6 с после запуска | встроенная текстура APX с полной цепочкой мипов вместо одного уровня | 6 |
| `0x008CAE17` (чтение `00000014`) | конец вступительной сцены, создание объектов этапа | `Destructible` с metamodel без состояний `DestructibleState` | 14 |
| `0x004420F3` | загрузка меню | `LuaAudioScript`, `VariableSwitch`, `VariableOperator` в `gf2/frontend`: нет менеджера переменных | 28 |
| `0x00480E03` | загрузка меню | скрипт Lua в меню: нет состояния Lua | 28 |
| `0x0042138B` | старт с `-stream` | два потока верхнего уровня; флаги после `-stream` (читаются как потоки); один раз — гонка запуска с `-stream` (повтор прошёл) | 32, 58, 59 |
| `0x00890CEB` | старт с `-stream` | один дочерний поток (`-stream gf2 cuba\local`) | 32 |
| `0040C278` | телепорт из перехвата `0x0068B04B` | запись вне кадра: буфер команд кадра `0x01206880` пуст | 34 |
| `0x6E756F7B` | вход в стартовый триггер Миссии 3 у (232; 14; −345) | миссия запущена `live send cp_325_start_now` со старта `-stream` без сюжетного состояния; то же без мода | 63 |

Зависания (не падения): вызов `As` у всех объектов таблицы групп — главный поток встал (этап 49);
проверка каждого чтения через `VirtualQuery` под Wine — больше 3 минут (этап 34).

О падении `0x6E756F7B`: после `cp_325_start_now` текущий чекпоинт — `cp_325`, идут экраны «Compound
UNLOCKED», древо семьи, «Взгляд дона»; падение — при входе в триггер. Вывод источника: быстрый путь
годится для чекпоинтов, но не для прохождения заданий. Этап 99 снял отчёт: падает рабочий поток заданий
(`0x00AC3290`) на вызове испорченного указателя из запроса, сразу после смены чекпоинта на `cp_326` —
[вопрос](../questions/crash-6e756f7b.md).

Как стенд видит падение: Wine показывает окно отладчика, процесс жив; `await` ищет в `wine.log`
строку `Unhandled … starting debugger` и пишет `the game crashed: …` в `timeline.txt`. С модулем
`doctor_crash.asi` в тени остаётся ещё и отчёт с минидампом (`doctor-toolkit crash-report show ТЕНЬ`) —
[опыт](crash-reports-bench.md).
