# Правка мира вживую: объект, коллизия, отмена (этап 47)

Гавана у ворот аэропорта, самолёт G-STAN — `Destructible` `ff32c936…` потока
`gf2/cuba/local/yuri/medium/zone4`. Ходьба — `teleport` в начало пути, `hold w 4–5`, `live player`.

| Проверка | Результат |
|---|---|
| классы | `Destructible`, `Entity` — поддерживаются; `Player`, `CommonNPC` (`PartedAnimated`), `AICarBehavior` — «sets its matrix its own way» |
| поворот и сдвиг | `rotate --by 30`, `move --by 4,0,-3` — «turned 30.0°, collision placed again (1 part(s))», в следующем кадре |
| коллизия на новом месте | самолёт сдвинут на (+10, 0, −10); путь по `x = 288` от `z = 355`: без сдвига до `z = 386,6`, со сдвигом игрок уведён в сторону и встал на (280,4; 370,2) |
| старое место свободно | путь по `x = 278` до `z = 387,0` без помех; после `undo` — упирается на `z = 375,3` |
| скрыть и показать | скрыт — путь свободен (`z = 387,0`); показан — упирается (`z = 375,3`) |
| логика | `disable --logic` — `logic off`; `undo` — снова принимает сообщения |
| отмена | `undo --all`: четыре правки в обратном порядке, место и поворот как до правок |
| перенос в рабочее пространство | `object commit` за 0,5 с: «Move object 4 (Destructible) in gf2/cuba/local/yuri/medium/zone4»; `live install --apply` — самолёт на (288,08; 0; 369,44) с поворотом 45°, целый |

Ни одного исключения в `wine.log` за семь сеансов; `verify` — оригиналы не менялись (27 файлов).

Найдено:

- Первая версия вынимала объект из мира целиком и возвращала (счётчик `+0x161`) — это перезапускает
  машину состояний metamodel. Теперь модуль переставляет только тела частей коллизии и скрывает через
  `SetVisible`.
- Объекты, привязанные к другим (`+0x110`), не двигаются (отказ).

Что неизвестно: самолёт (`Destructible` с состояниями по здоровью) после скачка на метры за кадр
показывает обломки — и без перестановки коллизии, и скрытый во время сдвига; сдвиг на 0,05–0,3 м —
цел. Причина не найдена. Записанный в рабочее пространство и загруженный заново — целый.
