## Статус и уверенность

Каждая заметка говорит, насколько ей можно верить:

- `status`: `known` — установлено; `partial` — известна часть; `hypothesis` — догадка, которую надо проверить; `unknown` — не известно; `planned` — запланированное исследование.
- `confidence` — на чём держится главное утверждение: `exe` — код исполняемого файла; `data` — файлы игры; `bench` — опыт в запущенной игре; `guess` — догадка.

Адреса exe и все наблюдения относятся только к изданию PC 1.0.789.0.
