# Ролики: секвенсор Trinity

Адреса — виртуальные, издание PC 1.0.789.0. Секвенсор читает команды ресурса `trinity_seq_master` и раздаёт их по таблице обработчиков `{u32 код, указатель}`. Координаты ролика — мировые, с привязкой к матрице объекта.

| Адрес | Что это | Источник |
|---|---|---|
| `0x00599720` | секвенсор: читает код команды и ищет обработчик в таблице | cutscenes.md §2.1 |
| `0x00E2BCE0` | данные: таблица обработчиков команд `{u32 код, указатель}` | cutscenes.md §2.1 |
| `0x00845A50` | обработчик текстовой команды `0x402` | cutscenes.md §2.1 |
| `0x00845960` | разбор имени текстовой команды | cutscenes.md §2.1 |
| `0x0059B300` | обработчик состояния эффекта `0x602` | cutscenes.md §2.1 |
| `0x00595610` | вычисление кривой камеры | cutscenes.md §3 |
| `0x00595950` | позиция по ключам, линейно между ключами | crates/doctor-toolkit/src/resource/trinity.rs |
| `0x0059BB50` | кривые позиции | cutscenes.md §9.1 |
| `0x0059BC30` | кривые поворота (порядок y, x, z) | cutscenes.md §3; cutscenes.md §9.1 |
| `0x00597370` | запуск секвенсора: получает от объекта структуру с матрицей и флагами | cutscenes.md §9.1 |
| `0x008473D0` | объект ролика, передающий секвенсору матрицу | cutscenes.md §9.1 |
| `0x0044B4E0` | копия матрицы объекта 4×3 → 4×4 | cutscenes.md §9.1 |
| `0x00599340` | начало кадра секвенсора: матрица привязки слота | cutscenes.md §9.1 |

## Что неизвестно

Состояния 1 и 2 эффекта `0x602` источник трактует как остановку только гипотезой.
