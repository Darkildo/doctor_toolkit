# Диалоги: загрузчики dlg и chv, узлы

Адреса — виртуальные, издание PC 1.0.789.0. Ресурс `dlg` — образ памяти дерева диалога со смещениями вместо указателей; условия и присваивания обращаются к «переменным» — номерам запросов движка.

| Адрес | Что это | Источник |
|---|---|---|
| `0x006FB320` | загрузчик `dlg` (проверка версии 4) | dialogues.md §2 |
| `0x00D60A4C` | данные: таблица методов класса-обработчика `DLG` | dialogues.md §2 |
| `0x006F0310` | перевод смещений `dlg` в указатели | dialogues.md §2 |
| `0x006EFF10` | классы узлов диалога | dialogues.md §2 |
| `0x00D5FEE8`, `0x00D604F4` | данные: первая и последняя таблицы методов видов узлов 0..0x2C | dialogues.md §2.1 |
| `0x006ECF70` | узел 2 — условие `==` | dialogues.md §2.1 |
| `0x006ED0A0`, `0x006ED1D0`, `0x006ED300` | узлы 3, 4, 5 — условия `!=`, `<`, `>` | dialogues.md §2.1 |
| `0x006EFE00` | узел 0x24 — присваивание | dialogues.md §2.1 |
| `0x00898480` | узел 0x20: ставит флаг x−0x13 разговорного NPC | dialogues.md §2.1 |
| `0x008982E0` | узел 0x21: ставит флаг x−0x1A | dialogues.md §2.1 |
| `0x006EBFF0` | запрос движка по номеру «переменной» условия | dialogues.md §2.1; dialogues.md §8 |
| `0x00898330` | чтение флагов 0..6 NPC (номера запросов `0x0C`..`0x12`) | dialogues.md §2.1 |
| `0x006F4840` | загрузчик `chv` (версия 3) | dialogues.md §3 |

## Что неизвестно

Названий у номеров запросов `0x006EBFF0` нет; то, что номера `0x0C`..`0x12` — флаги NPC, источник помечает гипотезой.
