# Навигационный граф: загрузка и обход

Адреса — виртуальные, издание PC 1.0.789.0. Граф навигации — образ объекта движка в памяти. По коду сверены проверка версии, перевод смещений, поиск по R-дереву, видимость и чтение свойств.

| Адрес | Что это | Источник |
|---|---|---|
| `0x005FA870` | проверка образа: буфер выровнен на 16 и слово `+8` равно 16 | navigation-graph.md вводная часть |
| `0x00601410` | перевод 17 смещений заголовка в указатели | navigation-graph.md вводная часть |
| `0x005FC5D0`, `0x00601999` | обход R-дерева по потомкам и братьям, сравнение квадрата расстояния до рамки | navigation-graph.md §3 |
| `0x005FC8C0` | бит видимости пары узлов в треугольной матрице | navigation-graph.md §3 |
| `0x005FC210` | чтение списка видимости как RLE (нулевой байт и число нулей) | navigation-graph.md §3 |
| `0x005FCAD0` | значение свойства: `данные + смещение экземпляра + смещение поля` | navigation-graph.md §4 |
| `0x005FFEB0` | поиск пути пропускает рёбра в узел с флагом `0x4000` | navigation-graph.md §5 |

## Что неизвестно

В игре пересобранный граф по этому документу не проверялся (отложено на этап 45).
