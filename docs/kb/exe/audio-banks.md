# Звук: банки sbk и поиск эмиттера

Адреса — виртуальные, издание PC 1.0.789.0. Игра находит звук по SDBM-хэшу имени эмиттера во всех загруженных сессиях; пулы банка читаются строго по порядку одним курсором.

| Адрес | Что это | Источник |
|---|---|---|
| `0x00436A90` | Lua `PlayEmx(name, …)`: хэширует имя и передаёт хэш в `0x005E49D0` | audio.md §3.5 |
| `0x00E30C18` | данные: строка `PlayEmx` | audio.md §3.5 |
| `0x005E49D0` | передача хэша эмиттера (→ `0x005F0560`) | audio.md §3.5 |
| `0x005F0560` | поиск эмиттера: идёт по списку загруженных сессий | audio.md §3.5 |
| `0x005F0490` | загрузка сессии: обход пулов, разбор инструментов и эмиттеров | audio.md §3.5 |
| `0x005F0990` | обход пулов одним курсором (записанные смещения, кроме 0x50 и 0x30, не читает) | audio.md §3.3 |
| `0x005F09E0` | разбор инструментов: к смещению банка прибавляет начало таблицы | audio.md §3.3 |
| `0x005F0A30` | разбор эмиттеров | audio.md §3.5 |
| `0x005F0B20` | поиск инструмента для эмиттера | audio.md §3.5 |
| `0x005F0BE0` | двоичный поиск ключа дорожки в lookup инструментов | audio.md §3.5 |
