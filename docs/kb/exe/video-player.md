# Видео: проигрыватель роликов vp6

Адреса — виртуальные, издание PC 1.0.789.0. Проигрыватель видео в `exe` опознаёт контейнер EA и AVI, декодирует VP6 и звук EA-XA; ролики лежат в `movies/<каталог>/<имя>`.

| Адрес | Что это | Источник |
|---|---|---|
| `0x00D087F0` | конструктор набора демультиплексоров, видео- и аудиодекодеров | video.md §2 |
| `0x00D0A6C0`, `0x00D0A6F0` | опознание контейнера EA по `SCHl` / `MVhd` | video.md §2 |
| `0x00D0A9B0` | разбор контейнера EA: кодек, ширина, высота, частота, число кадров | video.md §2 |
| `0x00D0DC90` | разбор `SCHl`: каналы, частота, кодек звука | video.md §2 |
| `0x00D0CFB0` | второй демультиплексор — AVI | video.md §2 |
| `0x00D18360`, `0x00D18370` | методы `VideoDecoder_Vp6`, возвращают `vp60` / `VP60` | video.md §2 |
| `0x009C7E50` | путь `movies/%s/%s` | video.md §2 |
| `0x009C82F0` | запуск ролика: третий аргумент — каталог (язык озвучки, язык текста, `Common`) | video.md §2 |
| `0x00936B90` | главное меню: `mainmenu.vp6` с флагами 7 из `Common` | video.md §2 |
| `0x00925F40` | титры: `credits.vp6` из `Common` | video.md §2 |
