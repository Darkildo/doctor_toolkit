# Вызовы отрисовки: кто зовёт `DrawIndexedPrimitive`

Адреса — виртуальные, издание PC 1.0.789.0. Привязка вызовов к функциям — по адресам возврата в записи кадра графического модуля (стенд), сами функции — по декомпиляции.

| Адрес | Что это | Источник |
|---|---|---|
| `0x0042FC70` | рисование списка элементов прохода (элементы по 0x20 байт, порядок — `u16` в `+0x1C`); 68–84 % вызовов кадра; места вызова рисования `0x0042FF31` (без смены материала: тени, глубина) и `0x004300C2` | renderer.md §11.3 |
| `0x0042F2D0` | материал и константы элемента (`секция, +0xC, +8, проход`) | renderer.md §11.3 |
| `0x0042EF20` | рисование одной секции меша (место вызова `0x0042F0C5`); 10–14 % вызовов | renderer.md §11.3 |
| `0x009D1A40` | деревья (шейдеры `TreeTrunk`, `Tree*Leaf`); 4–17 % вызовов | renderer.md §11.3 |
| `0x0060CB70` | ждёт готовности буфера индексов (`+0x28`), затем `0x0060CAE0` | renderer.md §11.3 |
| `0x0060CAE0` | обёртка `DrawIndexedPrimitive` (`+0x148`): `SetIndices` по кэшу, отложенные состояния, число примитивов | renderer.md §11.3 |
| `0x0060C9D0` | число примитивов по числу индексов и типу (полоса: − 2, список: / 3) | renderer.md §11.3 |
| `0x006102C0` | отложенные состояния рендера: отличия `0x011F39D8` от `0x011F3DD8` уходят `SetRenderState` | renderer.md §11.3 |
| `0x0060C8D0` | поток вершин (`SetStreamSource`) с кэшем | renderer.md §11.3 |
| `0x0120583C` | данные: буфер индексов, который стоит в устройстве (кэш игры) | renderer.md §11.3 |
| `0x01205838` | данные: объявление вершин, которое стоит в устройстве (кэш игры) | renderer.md §11.3 |
| `0x01164010`, `0x01164014` | данные: таблицы объявлений вершин по типу секции (`тип·8`) | renderer.md §11.3 |
| `0x00427333`, `0x0042C4D3`, `0x00506D27`, `0x00618F47` | места `CreateQuery(D3DQUERYTYPE_OCCLUSION)` — запросы видимости вокруг вызовов отрисовки | renderer.md §11.5 |

## Что неизвестно

- Что лежит в элементе списка прохода по `+8` и `+0xC` и кто строит и сортирует список.
- Что игра проверяет запросами видимости — [вопрос](../questions/occlusion-queries.md).
