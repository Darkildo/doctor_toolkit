# Свет, тональная кривая и таблицы цвета: код и данные

Адреса — виртуальные, издание PC 1.0.789.0. Таблиц света в `exe` нет: константы шейдеров приходят из ключей времени суток (`TODMessage`). Ниже — функции, которые читают эти ключи, и глобальные переменные, куда они попадают. Связь `SetSkyMessage` с константами неба источник помечает гипотезой по кадрам.

| Адрес | Что это | Источник |
|---|---|---|
| `0x009D5A00` | чтение ключа `SetSkyMessage`; кладёт `value & 0xFF` в `x` цвета | renderer.md §10.2 |
| `0x009D3680` | чтение ключа `LightingTODMessage` | renderer.md §10.2 |
| `0x0110AC2C` | данные: тень (атрибут 0 `LightingTODMessage`) → `g_shadowDensity` | renderer.md §10.2; renderer.md §10.9 |
| `0x0110AC30` | данные: «обёртка» света (атрибут 1) → `g_diffuseAmbient` | renderer.md §10.2 |
| `0x004317F0` | пишет плотность тени из `0x0110AC2C` и таблицы `0x0110AC40` | renderer.md §10.9 |
| `0x0110AC40` | данные: таблица пар плотности тени для разных проходов | renderer.md §10.9 |
| `0x00835D40` | чтение ключа `ToneMappingTODMessage` | renderer.md §10.2 |
| `0x01206A90` | данные: начало параметров тональной кривой (`0x01206A90…0x01206AAC`) | renderer.md §10.2 |
| `0x01206AAC` | данные: конец параметров тональной кривой | renderer.md §10.2 |
| `0x0041D7D0` | тональная кривая: гистограмма яркости буфера света (128 корзин) | renderer.md §10.3 |
| `0x01206A94` | данные: минимум на корзину гистограммы | renderer.md §10.3 |
| `0x01206A98` | данные: ограничение спада | renderer.md §10.3 |
| `0x01206AA0` | данные: смесь кривой с прямой; на стенде 0 | renderer.md §10.3 |
| `0x01206AB0`, `0x01206AE8` | данные: границы блока сплайна трёх «экспозиций» (`0x01206AB0…0x01206AE8`) | renderer.md §10.3 |
| `0x0042C1F0`, `0x0041CF70` | флаг качества включает тональную кривую (`0x0042C1F0` → `0x0041CF70`) | renderer.md §10.3 |
| `0x0041DDF0` | постоянная текстура кривой при нулевых экспозициях | renderer.md §10.3 |
| `0x01205958` | данные: переменная тональной кривой; на стенде 0 | renderer.md §10.3 |
| `0x01211240` | данные: вектор света (направление солнца) | renderer.md §10.4; renderer.md §10.9 |
| `0x0053D6E0` | берёт константы шейдера таблиц цвета (`AlchemyLUTShader`) | renderer.md §10.9 |
| `0x0052A170` | эффект вспышки: меняет `saturateColor` | renderer.md §10.9 |
| `0x0052EA40` | считает веса таблиц цвета из активных эффектов | renderer.md §10.9 |
| `0x01219388` | данные: активные эффекты таблиц цвета | renderer.md §10.9 |
| `0x0121930C` | данные: 6 × u32 — номера текстур таблиц цвета в таблице текстур | renderer.md §10.9 |
| `0x01219324` | данные: сила и веса таблиц цвета | renderer.md §10.9 |
| `0x01219344` | данные: число таблиц цвета | renderer.md §10.9 |

## Что неизвестно

Значения цвета солнца и доли рассеянного света (`g_lightColor`, `g_lightColorSH`) задаются кодом, их не нашли. Блум в редактор не перенесён.
