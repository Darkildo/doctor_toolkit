# Граф анимации: таблицы функций узлов

Адреса — виртуальные, издание PC 1.0.789.0. Узел графа анимации обрабатывают три таблицы функций по типу: выборка позы, длительность, обновление. Адреса — образа, разобранного Ghidra: на диске секция данных зашифрована защитой.

## Что неизвестно

17 типов узлов есть в таблицах, но в банках не встречаются. У типа 0x12 результаты объединяет код, закрытый защитой.
