# Речь и микшер: банки smb, события get, auc, mix

Адреса — виртуальные, издание PC 1.0.789.0. Звуковые ресурсы принимает один обработчик; реплику игра находит по 128-битному id в загруженных банках, а путь файла строит из имени.

| Адрес | Что это | Источник |
|---|---|---|
| `0x00455CF0` | обработчик звуковых ресурсов: регистрирует `MIX`, `SBK`, `SMB`, `MSX`, `AMX`, `GNX`, `AUC`, `FX` | audio.md §13 |
| `0x004560E0` | загрузка: выбор по типу ресурса | audio.md §13 |
| `0x004562F0` | `sbk`: отказ, пока не загружен `auc` | audio.md §13 |
| `0x004563C0`, `0x004CBD10` | `smb`: добавление в список банков, перевод смещений | dialogues.md §4 |
| `0x00456460`, `0x005E35E0` | `auc`: версия 11, категории, пулы, даки | audio.md §13 |
| `0x005DC510` | регистрация категории по хэшу имени с родителем | audio.md §13 |
| `0x004C9690`, `0x004C8CE0` | регистрация дака по хэшам имени и микса | audio.md §13 |
| `0x004565E0`, `0x004CB440`, `0x005DDE90` | `mix`: версия 15, перевод смещений каналов | audio.md §14 |
| `0x00456530` | регистрация микса по хэшу имени | audio.md §14 |
| `0x00455F50`, `0x004CBDC0` | поиск записи `smb` по id во всех банках: двоичный, по 16 байтам | dialogues.md §4 |
| `0x00456010`, `0x004CBEC0` | поиск записи `smb` по хэшу имени (`+0x6C`) | dialogues.md §4 |
| `0x004A84D0` | параметры записи `smb` → запрос воспроизведения | dialogues.md §4 |
| `0x004A8460`, `0x004A8580` | путь файла: `audiostreams\`, язык, папка из имени, `.snu` | dialogues.md §4 |
| `0x006F4840`, `0x006F4680` | `chv`: загрузка и поиск по GUID ресурса | dialogues.md §3.1 |
| `0x006F4CD0`, `0x006F4C10` | поиск события в `chv`: двоичный по хэшу | dialogues.md §3.1 |
| `0x006F38A0` | читатель `ChatterComponent`: четыре слота наборов речи | dialogues.md §3.1 |
| `0x006F3B80` | поиск события в слотах 3, 2, 1, 0 | dialogues.md §3.1 |
| `0x006F3EB0` | «сказать событие»: без записи `get` выходит | dialogues.md §6 |
| `0x006F77A0`, `0x006F73A0`, `0x006F15B0` | воспроизведение строки события; выбор строки `0x006F5190` | dialogues.md §3.1 |
| `0x006FE4B0`, `0x006FE750` | запуск потока реплики по id строки | dialogues.md §3.1 |
| `0x006F5FA0`, `0x006F5DD0`, `0x006F5D80` | `get`: загрузка (версия 3), поиск записи, двоичный поиск | dialogues.md §6 |
| `0x006F5530` | чтение байта `+0x20` записи `get` без проверки записи | dialogues.md §6 |
| `0x006F5940`, `0x006F58D0`, `0x006F5870` | пауза повтора и группы событий | dialogues.md §6 |
| `0x007E85B0`, `0x00D6FC18` | чтение полей `+0x0C`…`+0x14` для 69 событий; данные: их хэши | dialogues.md §6 |
| `0x006F2FD0`, `0x006F24D0` | `SimpleChatterBox`: конструктор и читатель атрибутов | dialogues.md §3.2 |
| `0x006F26D0`, `0x006F2890` | `SimpleChatterBox`: обработчик сообщений и «сказать» | dialogues.md §3.2 |
| `0x006F2070`, `0x006F2220` | реплика с говорящим и без него | dialogues.md §3.2 |
| `0x006F1890` | уровень важности 1–9 → приоритет 400…3000 | dialogues.md §3.2 |

## Что неизвестно

Читатели уровней канала `mix` и структура запроса воспроизведения не разобраны — см. [вопрос о полях](../questions/speech-bank-and-event-fields.md) и [о миксе](../questions/resource-format-mix.md).
