# «Взгляд дона» и HUD

Адреса — виртуальные, издание PC 1.0.789.0; проверено в Ghidra на этапе 114. «Взгляд дона» (карта стратегии) — член большого объекта интерфейса; в нём путевая точка игрока и выбранное заведение. HUD прячется счётчиком: каждый, кто прячет, потом показывает.

| Адрес | Что это | Источник |
|---|---|---|
| `0x01130054` | данные: объект интерфейса (0x1DD0 байт), создаёт `0x009201B0` | dev-menu-cheat-table.md §0.1 |
| `0x0091F920` | конструктор объекта интерфейса; члены `+0x30C`, `+0x380` («Взгляд дона»), `+0x550` (панель заведения), `+0x5B4`, `+0x6EC` | dev-menu-cheat-table.md §0.1 |
| `0x0112AF70` | данные: «Взгляд дона» (указатель) | dev-menu-cheat-table.md §0.1 |
| `0x0097A010` | конструктор «Взгляда дона», пишет `0x0112AF70` | dev-menu-cheat-table.md §0.1 |
| `0x009776B0`, `0x00976750` | деструкторы, обнуляют `0x0112AF70` | dev-menu-cheat-table.md §1.3 |
| `0x00979DA0` | поставить или снять путевую точку: `+0xA4/+0xA8/+0xAC` x, y, z узла курсора `+0xF8`, `+0xB4` «есть», `+0xA0` цель, `+0xB8` значок на карте | dev-menu-cheat-table.md §1.3 |
| `0x00979900` | показ маркера путевой точки | dev-menu-cheat-table.md §1.3 |
| `0x0092A020` | панель заведения: выбранное заведение `*(*0x0112AF70 + 0x160)`, владелец `+0x40` | dev-menu-cheat-table.md §4.3 |
| `0x01129C4C` | данные: HUD (указатель): `+0x5C` флаги (бит 15 — подсказка), `+0x60` счётчик скрытия | dev-menu-cheat-table.md §1.5 |
| `0x0093C210` | `Hud::Hide`, `fastcall`: счётчик +1, при 0 → 1 прячет интерфейс; 15 вызовов (телепорт, меню паузы, катсцены) | dev-menu-cheat-table.md §1.5 |
| `0x0093A2F0` | `Hud::Show`, `fastcall`: счётчик −1, при 0 возвращает интерфейс | dev-menu-cheat-table.md §1.5 |
| `0x0093B530` | показ подсказки обучения; ставит паузу тактов `0x0040EAC0(1)` | dev-menu-cheat-table.md §0.1 |

На стенде (этап 120, [опыт](../experiments/dev-menu-player-page.md)): `*0x0112AF70` не 0 с начала уровня, ещё до первого входа во «Взгляд дона», и тот же весь прогон; метка (`+0xB4` = 1) остаётся после выхода. Высота `+0xA8` — всегда 0 (ноль карты, не земля): у всех четырёх меток y = 0,000, и у метки на пирсе крепости, где рядом лестницы на высоте 16–20 м. `+0xB0` не 0 только внутри «Взгляда дона». Счётчик HUD `+0x60`: меню паузы и «Взгляд дона» прячут (+1) и после возвращают (−1), чужое скрытие не снимают; объект HUD за прогон не меняется.

Не выяснено: высота земли под меткой (её надо искать отдельно), когда пересоздаётся объект интерфейса (за уровень — ни разу), HUD после катсцены.
