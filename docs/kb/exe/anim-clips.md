# Анимации: банки bnk, клипы, декодеры

Адреса — виртуальные, издание PC 1.0.789.0. Банк анимаций `bnk` — образ памяти; игра перемещает его, привязывает к ригу и регистрирует именованные входы под SDBM-хэшем имени. Время клипа идёт в тиках 1/59,94 с.

| Адрес | Что это | Источник |
|---|---|---|
| `0x004621A7` | загрузчик: проверяет type id `rcb`/`bnk` и перемещает банк | characters.md §6 |
| `0x005709E0` | перемещение банка | characters.md §6 |
| `0x00462410` | привязка банка к ригу (`bnk+0x0C` = хэш скелета) | characters.md §6 |
| `0x00570860` | подготовка клипов (заполняет указатель на каналы `+0x2C`) | characters.md §6 |
| `0x00593BC0` | выбор декодера по схеме | characters.md §6 |
| `0x00579AA0` | декодер каналов, схема 3 | characters.md §6 |
| `0x0057C590` | декодер каналов, схема 4 | characters.md §6 |
| `0x0057D4E0` | декодер каналов, схема 1 | characters.md §6 |
| `0x0057A900` | декодер: место после семи костных каналов | characters.md §6.7 |
