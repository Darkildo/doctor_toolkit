# Мировая сетка: функции и данные

Адреса — виртуальные, издание PC 1.0.789.0. Мировая сетка решает, какие потоки зон грузить по положению игрока; данные — ресурсы `wgi`. Радиусы и бюджеты сверены чтением памяти игры на стенде.

| Адрес | Что это | Источник |
|---|---|---|
| `0x01129824` | данные: менеджер сетки (указатель); `+0x7C` число наборов мер, `+0x80` разделы, `+0x148` их число | wgi.md §4; game-bench.md §33 |
| `0x0088D6E0` | обновление раз в кадр: точка интереса — игрок и две точки впереди по ходу; затем приоритеты и загрузка у каждого раздела | wgi.md §4 |
| `0x0112E242` | данные: отладочный флаг «точка интереса — камера» | wgi.md §4 |
| `0x0088A960` | приоритеты ячеек раздела: `(1 − d / R) · 100`, 500 у ячеек «всегда», +5 загруженным | wgi.md §4 |
| `0x0088BB70` | загрузка раздела: по убыванию приоритета, порог 10, лимит числа и бюджет по `data_size`; выгрузка остальных | wgi.md §4 |
| `0x00888080` | вес ячейки: `data_size` потока и его включённых дочерних | wgi.md §4 |
| `0x0088AE10` | запрос потока ячейки (`0x00404280`) после предпосылок из таблицы потоков сетки | wgi.md §5 |
| `0x0088AF60` | выгрузка потока ячейки и счётчики предпосылок | wgi.md §5 |
| `0x0088BAD0` | выгрузка ячеек, не отмеченных в этом кадре | wgi.md §4 |
| `0x0088C4F0` | постройка раздела из `wgi`: узлы ячеек (0x50 байт), счётчик включений 1 у вида 0; карта потоков `0x00E541FC` | wgi.md §3, §5 |
| `0x0088C000` | разборка раздела: счётчики карты потоков | wgi.md §5 |
| `0x0088CC10` | загрузка ресурса `wgi`: проверка `type_id` и версии 7, смещения → указатели | wgi.md §2 |
| `0x00888D20` | конструктор `WorldGraphPartition` (фабрика `0x00683B60`, размер 0x290): `+0x50` до 10 `wgi`, `+0xAD` включён, `+0x278` меры, `+0x284` радиус, `+0x288` прибавка | wgi.md §4 |
| `0x00887E40` | читатель атрибутов раздела: 0 — включён, 1 — GUID мер; 2 и 3 пропускает | wgi.md §4 |
| `0x0088C9C0` | обработчик сообщений раздела: связь с мерами, радиус по маске (200 / 500 / 2 000 / 5 000), прибавка 5 | wgi.md §4 |
| `0x0088F290` | конструктор `WorldGraphMetrics` (фабрика `0x00683B30`): по умолчанию 50 МБ, 64 потока | wgi.md §4 |
| `0x0088ED50` | читатель атрибутов мер: 0 — маска LOD, 4 — бюджет в МБ, 5, 6 — лимит потоков | wgi.md §4 |
| `0x0088E230` | читатель `WorldGraphManualLoadSet` (конструктор `0x0088E0E0`): три группы GUID потоков, флаги, память, GUID мер | new-resources.md §3.6 |
| `0x0088A7B0` | приоритеты потоков включённого набора: 900+, 800+, 0 | new-resources.md §3.6 |
| `0x00890A80` | конструктор `ZoneStreamEnable` (фабрика `0x00687F30`, размер 0x1D0) | wgi.md §6 |
| `0x00890BD0` | читатель `ZoneStreamEnable`: атрибут 0 → SDBM → узел ячейки (`+0x1C0`) | wgi.md §6 |
| `0x0088DBF0` | поиск ячейки по хэшу имени во всех разделах, ближайшая к точке (`0x00888100` — в одном разделе) | wgi.md §6 |
| `0x00890CB0` | тик `ZoneStreamEnable`: игрок в единичном кубе объекта — счётчик включений узла +1, вышел — −1 | wgi.md §6 |
| `0x0047F960` | читатель `StreamSet` (конструктор `0x0047F180`, фабрика `0x00686C70`) | new-resources.md §3.6 |
| `0x00448140` | загрузчик ресурса SimGroup: хэш группы (0x10) ищется в таблице менеджера | simgroup.md §1.1 |
| `0x00447890` | поиск записи таблицы групп по хэшу (`+0xB0`, число `+0xB4`) | simgroup.md §1.1 |
| `0x00447070` | активна ли группа: флаги заголовка и запись таблицы (1 — вкл, 2 — выкл) | simgroup.md §1.1 |
| `0x00447AB0` | `(хэш, вкл, сразу)`: включить или выключить группу по хэшу | simgroup.md §1.1 |

## Что неизвестно

- Что делает коробка потока, зарегистрированная `0x00429430`; флаги ячеек `0x02` и `0x04` — см. [вопрос](../questions/wgi-cell-flags-and-stream-box.md).
- Имена сообщений `0x01206A20` (перестройка раздела), `0x012069C4` (тик) и `0x01206780` (из выгрузки потока) не установлены.
