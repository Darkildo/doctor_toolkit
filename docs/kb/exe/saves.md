# Сохранение и загрузка: функции и адреса

Адреса — виртуальные, издание PC 1.0.789.0. Объект с сохраняемым состоянием регистрируется в общем списке; сохранение обходит список и пишет блоки, загрузка раздаёт блоки объектам по идентификатору. Функции записи блоков — в [описании формата](../../formats/save.md) §3–§12.

| Адрес | Что это | Источник |
|---|---|---|
| `0x0122341C` | данные: список сохраняемых объектов (указатель): `+0xC` записи по 12 байт (идентификатор, интерфейс, маска), `+0x10` число | save.md §2 |
| `0x004C03C0` | сохранение: размер (`+4` интерфейса) и запись (`+8`) каждого объекта в буфер блоков | save.md §2 |
| `0x004C0540` | пересборка буфера: блоки отсутствующих объектов копируются как есть | save.md §2 |
| `0x004C0860` | обновление блоков на месте, если размер не изменился | save.md §2 |
| `0x004C0920` | загрузка: восстановление (`+0xC`) объекта по идентификатору блока; блок без объекта пропускается | save.md §2 |
| `0x004C0A60` | новая игра: восстановление всех объектов с пустыми данными | save.md §2 |
| `0x00463A80` | поиск объекта в списке по идентификатору | save.md §2 |
| `0x004639E0` | снятие объекта со списка (в деструкторах) | save.md §2 |
| `0x008F2690` | конструктор менеджера сохранений (таблица методов `0x00D81038`); регистрирует `iMsgGamePersistence*` | save.md §2 |
| `0x008F2460` | имя файла автосохранения: `GF2-%s-` и `autosave` | save.md §2 |
| `0x00ACD8A0` | чтение заголовков `RGMH` и `NMSD` для списка сохранений | save.md §1.1 |
| `0x00AD1330` | заголовок контейнера: магия `0x4D433032`, размеры, суммы | save.md §1.3 |
| `0x00AD2540` | проверка заголовка контейнера при чтении (ошибка 4) | save.md §1.3 |
| `0x00D373D0` | контрольная сумма CRC-32; таблица `0x00F0C828` | save.md §1.3 |
| `0x00442520`, `0x00442550`, `0x004425A0` | переменные сюжета: размер, запись, чтение блока | save.md §4 |
| `0x0067FD77` | создание менеджера переменных: ёмкость 320, флаги 0 | save.md §4 |
| `0x008BCBC0` | запись блока денег и семьи игрока (объект `*0x01129908`) | save.md §5 |
| `0x008C72D0`, `0x008C7940` | семьи: запись и чтение (версии 8–9) | save.md §6 |
| `0x006B0C90`, `0x006B1190` | здания: запись и чтение (версии 5–7) | save.md §7 |
| `0x008FD0F0` | запись блока чекпоинта и матрицы игрока | save.md §11 |
| `0x00705CF0` | запись блока оружия игрока | save.md §12 |
