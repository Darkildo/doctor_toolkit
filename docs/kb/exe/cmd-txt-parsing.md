# Чтение cmd.txt и разбор слов

Адреса — виртуальные, издание PC 1.0.789.0. Игра не читает свою командную строку: аргументы берутся только из файла `cmd.txt` в папке игры. Буфер командной строки консольных платформ в PC-сборке никто не заполняет.

| Адрес | Что это | Источник |
|---|---|---|
| `0x00E50B70` | данные: сюда `WinMain` кладёт `nCmdShow` | launch-flags.md §2 |
| `0x0068D010` | инициализация игры; читает `cmd.txt` и монтирует архивы | launch-flags.md §2; live-link.md §14.2 |
| `0x0068D0E5` | место вызова `0x0067C050` с буфером `0x011625D0` | launch-flags.md §2 |
| `0x0067C050` | сброс, чтение `cmd.txt`; есть файл — разбирается он, нет — буфер `0x011625D0` | launch-flags.md §2 |
| `0x0067BF30` | сброс разобранных аргументов | launch-flags.md §2 |
