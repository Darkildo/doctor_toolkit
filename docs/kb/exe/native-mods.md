# Платформа нативных модов: что она зовёт и патчит в exe

Адреса — виртуальные, издание PC 1.0.789.0. Всё, чем модуль `doctor_platform.asi` пользуется в `godfather2.exe`: регистрация и создание объектов классов, связки Lua, функции шины. Байты каждого места модуль проверяет до установки (`platform::CHECKS`, 51 место).

## Что неизвестно

Путь неупакованных записей не проверен в игре: в её файлах таких записей нет. Хранилище состояния для объектов мода и классы-сущности не разбирались — см. вопросы ниже.
