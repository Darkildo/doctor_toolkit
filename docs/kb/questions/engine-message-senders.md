# Кто в коде движка шлёт сообщения группы `Engine`

Этап 78 прошёл по всем местам exe, которые называют, подписывают и шлют сообщения (`research/bus_sites.py` → `data/gf2/bus_sites.tsv`, 2 747 строк). Из 645 имён движка отправитель в коде найден у 320 (было известно 9), слушатель — у 262, то или другое — у 430. В типах это поля `sent_by`, `engine_sites`, `engine_listens`; список — [сообщения движка](../messages/engine-messages.md).

Что осталось:

- 325 имён без найденного отправителя. Часть шлют объекты через переменные в своих полях (строки `[obj+0x…]`: 141 рассылка), часть — только слушают, часть шлют Lua, ролики и `score`.
- 30 рассылок и 18 доставок одному слушателю без имени (хэш собирается раньше окна прохода) и 14 рассылок из глобальных переменных без найденного имени (`var:0x…`).
- Условие отправки (при каком событии) для большинства мест не описано: известны адрес и данные.
- `function` в таблице — ближайший выровненный адрес, а не доказанное начало функции.

## Следующий шаг

Для строк `[obj+0x…]` определить класс по таблице методов слушателя (обработчик → таблица → конструктор → регистрация класса `0x004833A0`) и связать смещение с атрибутом; для `var:0x…` найти, где переменная получает хэш (косвенная запись). Условия отправки — по мере разбора систем (этапы 79, 85–92).
