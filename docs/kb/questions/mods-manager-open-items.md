# Менеджер модов: открытые вопросы

Открыто в менеджере модов: патч поверх мода, который только установлен и включён (не записан в игру), зависимость сам не получает (`--depends` руками); две неизвестные сборки игры с одной версией для мода неразличимы; удаление созданного потока оставляет пустые каталоги; нет блокировки файлов (две программы могут потерять запись в `registry.json`); отпечаток игры — только исполняемый файл; патчи `.vpat` с блоком ресурсов по типу и операциями «удалить» и «добавить» проверены только на синтетике; удаление ресурсов игры модом не поддерживается.

## Следующий шаг

Доработки по спросу; блокировка `registry.json` — по образцу проверки `revision` рабочего пространства.
