# Смысл байта 0x1D объекта SimGroup и бита 1 флагов

У объекта SimGroup не известен смысл байта 0x1D и бита 1 флагов.

## Что выяснено (этап 79)

Менеджер объектов перед созданием объекта (`0x00446BF0`, зовётся из `0x00446340`) читает оба поля записи объекта:

- бит 0 байта флагов `0x1C` — двоичная запись (класс в `+0x28` — хэш, а не строка);
- бит 1 — «у объекта есть пакет `Base`, и его атрибут 0 продублирован в байте `0x1D`»; без бита флаги создания считаются отсутствующими;
- байт `0x1D` — значение атрибута 0 пакета `Base` (флаги создания): без бита 0 объект не создаётся в режиме, когда функцию зовут с третьим аргументом не 0; любой бит, совпавший с маской `+0x24` менеджера, запрещает создание; бит 2 меняет пятый выходной аргумент.

В текстовой записи (бит 0 снят) тот же код обходит пакет `Base` (`0xFFD2E5B1`) и берёт атрибут 0 — отсюда и видно, что байт — его копия. Проверено на всех 111 518 объектах игры: бит 1 стоит ровно у 108 349 объектов с пакетом `Base`, байт равен атрибуту 0 (1 у 100 032, иначе 0) — `research/class_behavior.py corpus`, корпусный тест `the_second_flag_byte_of_an_object_is_its_base_attribute`.

Не прочитано: кто ставит маску `+0x24` менеджера и кто зовёт функцию в «строгом» режиме.
