# Граф анимации: данные ребёнка узла 8 и включение части узла 9

У ребёнка узла `0x08` (растяжение времени) есть данные для родителя из одного слова: 0 (443) или 1 (225); функции узла 8 их не читают, смысл не установлен. У узла `0x09` (включаемая часть) не до конца разобрано, когда и кем часть включается.

## Следующий шаг

Найти в exe читателя данных ребёнка у других типов родителя; проследить запись слота узла 9.
