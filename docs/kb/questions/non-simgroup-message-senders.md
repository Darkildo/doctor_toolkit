# Сообщения, которые посылают не SimGroup: Lua, ролики, `score`

Граф логики знает только отправителей из SimGroup. Сообщения шлют ещё скрипты Lua, ролики (`trinity_seq_master`) и документ очков `score`; поэтому, например, `mus_play_igc_01` «слышат, но никто не посылает».

## Что установлено (этап 78)

Отправка отделена от упоминания: `research/message_senders.py` строит `data/gf2/message_senders.tsv` — 583 строки, 202 сообщения, только доказанные кодом отправки.

- **Lua** — 98 сообщений, 397 вызовов в 13 из 30 скриптов потока `gf2/globals_global`: 394 `SendMessage("имя")` и 3 `SendMessageEx`. Имя везде константа, данных у `SendMessage` в скриптах игры нет ни разу. `SendMessage` (`0x004C8510` → `0x004C82C0`) и `SendMessageEx` (`0x004C86D0`) строят сообщение и зовут рассылку `0x00408A00`; `SendMessageEx` кладёт в данные объект с аргументами (до 8 пар «значение, тип») и возвращает то, что в него записал слушатель (`iMsgLuaGetVenueStats`, `iMsgLuaGetPlayerVenue`).
- **Ролики** — 33 сообщения, 38 текстовых команд `0x402` вида 1 в 29 кадрах: обработчик `0x00845A50` (ветвь `0x00845DB6`) даёт имя переменной сообщения (`0x00408240`) и зовёт `0x00408A00` с данными 0.
- **`score`** — 74 сообщения, 89 действий вида 1 (два одинаковых ресурса): интерпретатор действий `0x008948A0` ставит имя в очередь `0x00440590` всем слушателям с задержкой действия (в данных игры всегда 0) и данными 0. Остальные 1 130 строк ресурса — имена величин и событий счёта из его таблицы имён, а не сообщения (прежняя оценка «около 1200 имён сообщений» неверна). Подписка `score` на шину по строкам документа не проверялась.
- Из сообщений «слышат, но никто не посылает» (их было 1 097; после этапа 79 — 1 001: у 96 отправитель нашёлся среди выходов классов, прочитанных в коде) отправитель найден у 74 (Lua 29, ролики 8, `score` 38; одно — и Lua, и ролик). Ещё 78 сообщений из этих источников не использует ни один объект SimGroup (6 из них названы в exe). Из 7 569 «посылают, но никто не слышит» эти источники шлют 27 — слушателя это не даёт.

## Что неизвестно

- Слушатели вне SimGroup. Скрипты Lua подписываются таблицами обработчиков (`AddMessage` по ключам таблицы); по декомпилированным текстам это около 278 имён, из них 155 — из 7 569 «никто не слышит» (оценка по тексту, не по байт-коду; в файл не внесена). Слушателей в коде движка даёт `data/gf2/bus_sites.tsv`.
- `SetEarsAudioStreamStopMessage(поток, "имя")` (`0x004395D0`; в игре одно имя — `multiplayer_music_finished`) запоминает имя сообщения конца звукового потока; место отправки не найдено, в файл не внесено.
- Оставшиеся 1 023 «немых» сообщений: отправитель — код движка по имени из данных (атрибут объекта) либо никто.

## Следующий шаг

Слушателей Lua снять с байт-кода (ключи таблиц, по которым идёт цикл с `AddMessage`) и добавить в каталог; найти в exe, кто читает имя, сохранённое `SetEarsAudioStreamStopMessage` (объект потока, строка по `+4`).
