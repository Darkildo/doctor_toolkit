# Ограничения просмотра и правки уровней в редакторе

Известные ограничения редактора уровней: деревья (`treemodel`) стоят без ветра; объекты без `Entity.CMD_SetModel` показываются маркерами, даже если модель у них есть другим путём (`Animated`, персонажи, оружие и предметы); текстуры правок рабочего пространства в 3D не показываются; нет правки общего поля нескольких объектов разом, копирования между уровнями через буфер обмена и привязки к поверхности.

## Следующий шаг

Доработки редактора по спросу; для моделей без `CMD_SetModel` — найти, каким путём объект получает модель.
