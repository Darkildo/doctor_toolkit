# Как игроку доверять автору кода мода

[Менеджер модов](../engine/native-mod-install.md) перед установкой кода показывает имя автора из `mod.json` и SHA-256 каждого файла и ставит код только после ответа игрока. Имя автора в файле мода может написать кто угодно; хэш говорит только, что файл тот же, что в моде.

Не решено: нужна ли подпись автора (ключ, которому игрок доверил один раз) или список доверенных авторов, чтобы обновление кода того же автора не требовало нового вопроса; где хранить ответы, чтобы они переживали переустановку игры (сейчас — в папке игры).

## Следующий шаг

Решение владельца проекта: оставить вопрос на каждую новую сборку кода (как сейчас) или ввести подписи. При подписях — поле подписи в разделе `native` (новая версия формата не нужна, если подпись только ослабляет вопрос) и хранение ключей в настройках программы.
