# Новые события речи: своя запись `chv` и `smb`

Решено на этапе 83: новая реплика с новым событием делается одной операцией и звучит в игре.

## Ответ

- Реплике нужны четыре вещи: файл `.snu` в архивах по пути, который игра строит из имени; запись в загруженном банке `smb` с новым id; строка события в `chv` говорящего; запись события в `get` — её игра читает без проверки (`0x006F5530`), а общий путь без неё молчит (`0x006F3EB0`).
- Записи `smb` отсортированы по id, события `chv` и записи `get` — по хэшу: игра ищет двоичным поиском (`0x004CBDC0`, `0x006F4C10`, `0x006F5D80`).
- Инструменты: `voice-add`, мастер редактора «Новая голосовая реплика», формат мода версии 4 несёт звук.
- На стенде: событие `DOCTOR_TEST`, тон 2468 Гц — слышен в записи звука после каждого сообщения-запуска, в том числе из мода; субтитр новой реплики виден — [опыт](../experiments/new-voice-line.md).
