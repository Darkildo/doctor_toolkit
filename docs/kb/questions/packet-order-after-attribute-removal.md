# Порядок пакетов после удаления и возврата атрибута

Удаление атрибута, после которого пакет совпал с другим, и возврат значения дают те же значения, но другой порядок пакетов: результат не побайтно равен оригиналу.

## Следующий шаг

Запоминать исходный порядок пакетов при правке, если побайтное равенство понадобится (сейчас на игру не влияет).
