# Атрибут 2 (`flags`) `TriggerAuto`

Значение 2 атрибута 2 (`flags`) `TriggerAuto` стоит у 7 объектов (инициализация звука); смысл не проверен.

## Что выяснено (этап 79)

Обработчик `0x00477EF0` прочитан до конца.

- Бит 1 (значение 2 — единственное в игре, 85 объектов): отложенная отправка ставится в очередь `0x00440590` с флагом 4 — запись переживает сброс очереди. У звуковых объектов это значит: сообщение инициализации дойдёт, даже если очередь сбросят при загрузке.
- Бит 0 (1; в игре не встречается): после срабатывания объект ставит себе в хранилище состояния метку `0x137726B7`. Сам класс её не читает — её читает фильтр создания объектов `0x0043D650`: объект с меткой больше не создаётся, то есть срабатывает один раз на сохранение, а не при каждой загрузке потока.

Подписка на `iMsgPostSpawnInitialize` — в конструкторе `0x00477DB0`, приоритет `0x7FFF`. На стенде: все загруженные `TriggerAuto` с выключенным слушателем — [опыт](../experiments/class-state-in-game.md).
