# По какому правилу ресурс лежит в нескольких потоках

У 13 020 ключей ресурсов есть копии в других потоках: 164 550 лишних копий, 55 % распакованных данных всех потоков. Правило раскладки установлено по ссылкам на всей игре; не вычисляется только, какие общие ресурсы сборщик выносил в библиотеки выше пользователей.

## Что известно

- Поток видит ресурс, если держит его сам, его предпосылка по TOC или поток, который грузят данные его SimGroup (GUID — хэш потока в TOC: `InterestingObject.8`, `StreamSet`, `Animated.4`, `WorldGraphManualLoadSet`, `Door.23`). Так находят копию 99,76 % пар «ресурс — поток, который на него ссылается» (291 438 из 292 145).
- Копия лежит в потоке, который ссылается на ресурс (99,4 %), или в общей предпосылке таких потоков (941 копия: текстуры в `<город>/local` и `globals_global`, персонажи и риги в папках роликов, материалы машин в `vehicle_shared`), или в потоке, который пользователи грузят данными (164). Не объяснены 77 копий из 202 909.
- Правило `place` — копия в каждом потоке-пользователе, кроме того, чья предпосылка тоже пользователь, — даёт в точности держателей у 38 672 ресурсов из 40 065 (96,5 %); точность 99,37 %, полнота 76,92 % (общие копии игра держит одной выше).
- Вынос в библиотеку по числу пользователей или по пакету текстуры не вычисляется: порога нет.
- Пользователи без копии (707): 706 пар — материалы `from` списков замен (`materialswaplistresource`) зданий Нью-Йорка, у которых `from` лежит в соседней зоне уровня (414), заглушек на картах мультиплеера (244) и 48 из других уровней; одна ссылка на граф. Записи отрисовки мешей свой материал находят всегда: `check-refs` по всей игре не называет ни одного меша.
- `materialswaplistresource` — пары замен материалов по CRC-32 имени; ids ресурса — GUID объекта SimGroup того же потока (все 188).
- Меш находит материал по хэшу имени в общей таблице материалов всех загруженных потоков, но только в момент своей загрузки; без материала запись отрисовки не рисуется. Из одноимённых материалов действует первый загруженный ([таблица материалов](../exe/material-table.md)). Материал соседней зоны поэтому находится, только если зона загружена раньше, и `place` его достижимым не считает.
- Библиотека: `navigation::placement` — пользователи, держатели, пользователи без копии и потоки для новых копий (`copy_streams`, `place`, `place_by`); `StreamHashes` — то же правило «данные грузят поток» для проверки ссылок без индекса.
- Тулкит по правилу: `check-refs` считает и потоки, которые грузят данные (неразрешённых ссылок по игре 54 918 вместо 55 034 — остались ссылки на 5 текстур движка), и ловит меш раньше своего материала; правка материала идёт во все копии с тем же хэшем имени; `check-edits` называет потоки, куда нужна копия, и предупреждает о копиях с разными данными (resource-placement.md §6.1).

## Следующий шаг

На стенде: ищет ли игра материал `from` списка замен в таблице материалов или только сравнивает хэши (706 пар; у `genna/high/filler_125_15` — работает ли замена без зон с `from`). Отдельно — кто называет 1 470 эффектов зон и 2 636 банков роликов, на которые не ссылается ничто прочитанное.
