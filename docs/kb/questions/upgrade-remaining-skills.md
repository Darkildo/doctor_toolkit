# Что меняют остальные атрибуты `UpgradeData`

Значения видны, но что они меняют, по данным не определить: Handgun/Heavy Weapons Specialization (44 = 2/3/5 и 47 = 0.9/0.8/0.7; 51 = 2/3/5 и 54 = 0.925/0.85/0.75), Marksman (45, 46 = 0.6; 52, 53 = 0.75), Combat Reflexes (26, 33 = 1.25/1.5; 34 = 5/6), Ready Weapon (36–41 = 1.5), Extortion (30 = 30), Dangerous Appearance (25 = 0.5), Specialty Focus (24 = 0.75/0.5), Vice Grip (28 = 0.5).

## Следующий шаг

Проверять подписи описаниями навыков в меню игры (строка из атрибута 2 подставляет значение), как сделано для Heart и Health Regen.
