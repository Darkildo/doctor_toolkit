# Слова `0x5C`–`0x68` команды `0x205` и хэш блока `0x08` роликов

У команды `0x205` не известен смысл слов `0x5C`–`0x68` (1384 или 120, 8, 1, 0); не известен хэш блока `0x08`.

## Следующий шаг

Разобрать обработчик команды `0x205` в секвенсоре.
