# Отправитель сообщения в игре не известен

У шины нет отправителя: в сообщении только хэш, данные и флаг. На графе «вживую» зажигаются все узлы, которые могут послать сообщение. Найти отправителя можно по стеку вызова шины (объект, чей обработчик сейчас выполняется) — не сделано.

## Следующий шаг

В модуле связи при перехвате `0x00408A00` пройти стек до обработчика объекта и отдавать GUID отправителя в протоколе.

Запланировано: [Этап 78: Шина сообщений](../research/stage-78.md).
