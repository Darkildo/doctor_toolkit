# Чем на стенде выбрать вариант в меню разговора

Меню выбора F2F на стенде появляется (мод «торговец»), но вариант не выбирается ничем: стрелки, W/A/S/D, цифры, цифровая клавиатура, мышь, сочетания — без результата.

По коду выбор читает условие `0x1E` автомата `PlayerF2FSM` (`0x007CC4F0`): действия `F2FDecisionUp/Down/Left/Right` карты `basic_aiming_player.cec` (кнопки 1, 2, 4, 8). При входе в состояние выбора клавиатура и мышь переключаются на раскладку «Face 2 Face Dialog» (`0x006913C0(0xC)`, раскладка строится в `0x00692340`); её кнопки привязаны к настраиваемым клавишам, по умолчанию — стрелки и цифровая клавиатура (`0x006A1280`…). Устройства на стенде назначены (`*0x012233B4 + 0x564` = 4, `+0x565` = 5).

Подозрения (догадки): после старта через `-stream` нет профиля с настройками управления, и привязки пусты; либо действие отсекает маска контекста `0x00C8` записей `F2FDecision*`.

## Следующий шаг

1. Повторить в игре, запущенной через меню (загрузить сохранение у ворот аэропорта Гаваны с модом): если выбор стрелками работает — причина в старте `-stream`, чинить в `fix_input` модуля связи.
2. Иначе — в Ghidra пройти `0x00465530` (поиск действия в картах порта) с действием `F2FDecisionLeft` и посмотреть, что возвращает опрос кнопки 4 раскладки `0x01129C30`.
