# Динамические тела: масса, инерция, разрушаемые предметы

Новая коллизия, собранная тулкитом, всегда неподвижна: динамические тела (масса, инерция, разрушаемые предметы) не создаются.

## Следующий шаг

Разобрать поля динамических тел в `hkx` игры и научить сборщик их писать; проверить на стенде.

Запланировано: [Этап 96: Персонажи, модели, физика](../research/stage-96.md).
