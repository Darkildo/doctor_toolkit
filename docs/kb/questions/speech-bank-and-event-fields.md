# Смысл параметров записи `smb` и полей записи `get`

Оба формата пишутся побайтно, но часть полей названа только по значениям.

## Что известно

- `smb`: флаги 0x01 (папка языка в пути) и 0x40 (суффикс `.snu`) — по коду `0x004A8580`; категория, второй хэш и «дак» — хэши имён `auc`; шесть `f32` и слово `+0x30` игра копирует в запрос воспроизведения (`0x004A84D0`).
- `get`: пауза повтора `+0x08` и группы в битах 12–19 флагов — по коду (`0x006F5940`, `0x006F58D0`); к приоритету строки прибавляется младший байт слова `+0x20` (`0x006F5530`).

## Что неизвестно

- `smb`: `+0x18`, `+0x1C` (по значениям — дистанции), `+0x20`, `+0x24`, времена `+0x28`, `+0x2C` (свои у каждой записи), слово `+0x30` (90), второй хэш `+0x38` (`35048678` у речи — имени нет), флаги 0x04 и 0x08.
- `get`: `+0x04` (1.0), `+0x0C`, `+0x10`, `+0x14` (читаются для 69 событий из таблицы `0x00D6FC18`), ранг `+0x18`, имена флагов, старшие байты приоритета.

## Следующий шаг

Разобрать структуру запроса воспроизведения, которую заполняет `0x004A84D0` (смещения `+0x0C`…`+0x64`), и её читателей в `0x005E2A50`; для `get` — функцию `0x007E85B0` и её потребителя; сверить времена `+0x28`, `+0x2C` с длительностью файлов по корпусу.
