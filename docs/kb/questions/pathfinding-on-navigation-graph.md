# Поиск пути по навигационному графу

Формат `graph` разобран (узлы, рёбра, таблица путей), но как игра ищет путь по графу, не разобрано; в редакторе поиска пути по графу нет.

## Следующий шаг

Разобрать обход графа в exe (см. заметку exe о навигационном графе), повторить поиск пути в тулките и сверить с движением прохожих на стенде.

Запланировано: [Этап 88: ИИ](../research/stage-88.md).
