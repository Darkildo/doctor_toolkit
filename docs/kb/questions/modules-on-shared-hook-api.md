# Перевод модулей тулкита на общий API перехватов во время работы

Этап 80 сделал общим то, что не требует правки модулей: реестр всех мест, которые патчат `doctor_live`, `doctor_render`, `doctor_crash` и `doctor_platform` (`platform::CLAIMS`, 52 места), тесты пересечений и проверку, по которой платформа отказывает модам. Сами три модуля по-прежнему ставят свои перехваты сами в `DllMain` и о занятом месте узнают только по несовпавшим байтам.

Слабые места: список мест модуля связи в реестре собран руками по его коду; перехват, поставленный чужим ASI-модом (не через платформу), реестру не виден.

## Следующий шаг

1. Экспорт платформы `doctor_platform_claim(адрес, длина, владелец)`; модули зовут его перед патчем, если платформа загружена, и не ставят перехват при отказе.
2. Одна таблица мест модуля связи в `doctor-toolkit-live`, из которой берут и `CLAIMS`, и его установка.
3. Повторить на стенде проверки модулей: журнал и все объекты, отладка, профиль, графический модуль, отчёт о падении.
