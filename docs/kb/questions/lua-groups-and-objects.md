# Откуда скрипту Lua брать объекты игры (группы, функция `Base`)

Группы с объектами игры из своего скрипта не проверены: не известно, откуда скрипту брать объекты — через функцию `Base` или из данных сообщений.

## Следующий шаг

Найти в exe регистрацию `Base` и функций групп, описать аргументы и результаты; проверить на стенде на известном объекте уровня.
