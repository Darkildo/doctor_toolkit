# Формат ресурса `grt` не разобран

Тип `grt`: наборы звуков реакций NPC (`npc6_arm_break_01.emx`), один ресурс. Разбора в тулките нет.

## Следующий шаг

Выгрузить ресурсы (`doctor-toolkit dump <игра> --type grt`), описать раскладку и найти загрузчик в exe.
