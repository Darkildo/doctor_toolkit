# Вертикальный угол обзора: 36,0° в покое и 41,2° на бегу?

В документах два вертикальных угла игры без графического модуля: 36,0° (замеры этапа 58 при 4:3, 16:9 и 21:9) и 41,2° (исходное значение в прогонах `FOV90`/`FOV75` этапа 59, 1280×720). Оба получены на стенде командой `live camera`.

Расчёт их сводит. Менеджер камер отдаёт 60° по горизонтали при 16:9, на бегу — 67,5° (трассировка `SetFov` в `0x00425FE4`). Вертикальный угол — `2·atan(tan(угол/2) · 9/16)`: для 60° это 36,0°, для 67,5° — 41,2°. С `fov=90` (множитель тангенса 1,732) из 41,2° получается 66,1°, из 36,0° — 58,7°; оба числа есть в замерах. 51,9° при `fov=75` лежит между расчётом для покоя (46,7°) и бега (53,1°) — похоже на камеру в переходе.

Догадка: замеры этапа 59 сняты во время ходьбы (`hold w`), когда камера уже перешла на 67,5°. Отдельного замера «покой против бега» при одном окне нет.

## Следующий шаг

На стенде, окно 1280×720, без графического модуля: `live camera` в покое, затем во время `hold w` на 6 с и через несколько секунд после остановки. Ожидается 36,0°, 41,2° и снова 36,0°. То же с `fov=75`: 46,7° и 53,1°.
