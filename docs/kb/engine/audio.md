# Звук

Звук построен на EA AudioCore (SndPlayer, AEMS). Управляют им скрипты [Lua](lua.md) и события клипов [анимации](animation.md); во всех звуковых файлах кодек EA-XAS v1.

## Что известно

- Три хранилища: банки `sbk` (8 ресурсов в потоках: 942 эмиттера, 2 938 вариаций, 2 399 сэмплов, 40,8 мин); архивы `GODFATH0..2.viv` (BIGF, 4,7 ГБ, 24 913 файлов `audiostreams\*.exa.snu` — речь английская и `es`, музыка); банки речи `smb` (59: id звука → файл `.exa` архивов).
- Банк `sbk` (`sbnk`, версия 206) — образ для загрузки на месте: метаданные сессии и секция сэмплов `sdat`. Самый большой — `gf2/globalfolder/audio/emx_global_folder_stream` (855 звуков из 942).
- Загрузка банка: `0x005F0490` → обход пулов одним курсором (`0x005F0990`; записанные смещения, кроме 0x50 и 0x30, не читаются), разбор инструментов (`0x005F09E0`) и эмиттеров (`0x005F0A30`). Инструмент эмиттера ищется двоичным поиском (`0x005F0BE0`); не найден — запись обнуляется, звук молча пропадает. GUID сессии игра заменяет при загрузке.
- Поиск звука по имени: Lua `PlayEmx(name, …)` (`0x00436A90`) хэширует имя (`0x004DAFD0`, SDBM нижнего регистра) → `0x005E49D0` → `0x005F0560`: перебор загруженных сессий и их lookup эмиттеров подряд; при одинаковом имени в двух банках играет первый по списку. Имя нужно с `.emx`: без него возвращается нулевой указатель.
- Имён эмиттеров в банках нет; подобрано по хэшу 386 из 905 (`data/gf2/emitter_names.txt`).
- Архивы: при запуске монтируются `GODFATH0.VIV` … `GODFATH12.VIV` по порядку, какие есть (цикл с `0x0068BF87` в функции запуска движка `0x0068BD30`, число 13 — `0x00E2F000`; `rw::core::BigHandler::AddArchiveFromFile` `0x00B901D0`). Открытие (`0x00B90FB0`) берёт первый архив, где имя есть; отдельных файлов `audiostreams\…` на диске игра не ищет. Поэтому замены кладутся в накладной архив с номером 0, а архивы игры сдвигаются на номер выше (см. [файлы](file-system.md)).
- Файл SNU: заголовок SNR (8 байт big-endian: кодек 4, каналы, частота; речь и музыка — 32 000 Гц) и блоки SNS; в метаданных речи — чанк `LCH2` с субтитрами реплики на всех языках.
- События речи — ресурс `get` (один, в `globals_global`): 1372 записи по 36 байт, ключ — `sdbm(lower(имя события))` (`CREW_IM_DOWN_MEDIC`, `F2F_TAKEOVER_START`, `PHONE_*`), вес, задержки повтора, категория, флаги. События речи персонажа — `chv` (259), на них ссылается `ChatterComponent`.
- Микшер: `auc` (2 одинаковых ресурса) — дерево из 49 категорий (корни `DIALOG`, `MUSIC`, `SFX`), пулы банков и «даки»; `mix` (43) — снимки: уровни категорий по хэшу имени. Все звуковые ресурсы принимает один обработчик (`0x00455CF0`); банк `sbk` не загружается, пока не загружен `auc` (`0x004562F0`). Подробно — [адреса речи и микшера](../exe/speech.md).
- Потоковый звук: запись `smb` находится по 128-битному id двоичным поиском (`0x00455F50`), путь файла строится из имени (`0x004A8580`). Новая голосовая реплика проверена в игре — [опыт](../experiments/new-voice-line.md).
- Прочие ресурсы звука: `grt` (наборы звуков реакций NPC). Ссылки `emx` в metamodel (`Door.CMD_Set*Audio`) — тип `0x32293930`, ресурсов такого типа в потоках нет.
- Lua управляет: эмиттерами (`PlayEmx`, `StopEmx`, `SetEmxVolume`…), потоками музыки (`PlayStream`, `PrimeStream`, `StopStream`…), микшером (`ApplyMix`, `RemoveMix`), эффектами. Скрипты запускают объекты `LuaAudioScript`; параметры музыки «по накалу» (насилие, прицеливание) — объекты `*Tweaker` в `globals_global`.
- Звук роликов `.vp6` — другой кодек, EA-XA (см. [видео](video.md)). Поток звука движка — `RWAudioCore Dac`.
- Проверено в игре: замена и новые вариации, новый эмиттер в банке на 855 звуков, замена потокового звука через накладной архив.

## Что неизвестно

- Смысл части полей записей `smb` и `get` — [вопрос](../questions/speech-bank-and-event-fields.md); уровни канала `mix` названы по данным — [вопрос](../questions/resource-format-mix.md).
- Ссылки на эмиттеры по ключу lookup (свёртка GUID ассета) — `emx` дверей в metamodel — не проверены; ключ по имени не вычисляется.
- Формат `grt` не разобран. [Новая категория звука и правка микса](../questions/new-audio-category-in-game.md) в игре не проверены.
- Проверку версии 206 в PC-сборке найти не удалось.
