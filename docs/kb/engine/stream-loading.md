# Потоки `.str` и их загрузка

Все ресурсы игры лежат в потоках UStream (`.str`): 2300 файлов, 212 544 ресурса, 25 таблиц `.toc`. Поток — единица загрузки; ресурс доступен, пока загружен его поток.

## Что известно

- Файл: заголовок 12 байт (`3slo`, смещение `0x0C`, версия 2), страницы по `0x20000`, блоки `SHOC` (подтипы `SHDR`, `SDAT`, `Rpak`) и `FILL`. Ресурс — `SHDR` (0x20 байт) и блоки данных до следующего `SHDR`.
- `SHDR`: политика [памяти](memory.md), выравнивание, `type_id` (SDBM тега), четыре id — один 128-битный GUID ресурса, размер. Формы GUID: id × 4; `0, type_id, хэш пакета, хэш имени` у `tg4h`/`tg4d`; `~id` меша у `meshvolatile`; настоящий GUID с логином автора у `graph` и `materialswaplistresource`; нули у одиночных типов (`simgroup`).
- Загрузчик ресурса `0x00421470` (из разбора `SHDR` `0x004D0DB0`): ищет GUID в общей таблице загруженных ресурсов `0x00421170`; найден — счётчик ссылок +1 и данные пропускаются; иначе обработчик типа (таблица `0x01223980`, регистрация `0x0049C6E0`), выделение, регистрация `0x00421550`, привязка к потоку `0x004212B0`. Тип в ключ не входит, нулевой GUID не регистрируется. Глобальной таблицы «id → поток» нет.
- `StreamManager` — `*0x0122337C`: `+0x6C` список загруженных (имя `+8`, длина `+0xC`), `+0x84` — поток, объекты которого создаются сейчас; запись по id — `0x004025A0` (корзины `+0x50`, число `+0x54`); `+0x24` записи — состояние: 1 запрошен, 3 загружен, 2 и 4 на выходе.
- Запрос `0x00403A50(имя, приоритет, 0, 0, 0)` (`thiscall`, `RET 0x14`, приоритет по умолчанию 32768): ищет поток в TOC, иначе грузит `<имя>.str` по имени с фиктивным GUID `badbadba beefbeef eac15a55 91100911` — поток без записи в TOC загружается (проверено в игре).
- TOC версии 10 (magic `0x9CBA7B28`): записи отсортированы по хэшу (двоичный поиск `0x004A8180`); хэш — свёртка GUID потока `((a·33 + b)·33 + c)·33 + d` (функция `0x00401F40`; та же формула внутри поиска `0x004A82B0`). Игра держит до 32 TOC (`0x004040D0`). `data_size` — вес потока в бюджете раздела [мировой сетки](zones.md) (`0x0088BB70`, `0x00888080`): завышенный выталкивает соседние зоны.
- Загрузка записи `0x00403C40`: сначала предпосылки `f[0] + (f[2] & 1)`, затем сам поток (`0x00404590`), затем `f[1]` дочерних. Цепочка уровня: `globals_global` → `miami_global` → `miami` → `miami\local` → зоны, террейн, задания.
- Дочерний поток (флаги `0,0,5,0`) сам не грузится: загрузка родителя `0x00403C40` просит каждого ребёнка у `0x00404590`, а тот смотрит флаги записи в памяти (`+0xA`): бит `0x8` — грузить, `0x10` — нет, `0x4` (`LOAD_DISABLED_DEFAULT`) — нет. Бит `0x4` стоит у всех 110 дочерних потоков игры. Бит `0x8` ставит действие SimGroup `EnableDisableStreams` (`0x008142F0` → `0x00406230`, снимает `0x00406280`); работает и для обычного потока. Сохранение хранит этот бит.
- Дочерний поток **без** бита `0x4` (`0,0,1,0` в списке детей родителя; `add-stream --with-parent --auto-load`) игра открывает при каждой загрузке родителя и выгружает с ним — проверено в игре на этапе 84 ([опыт](../experiments/world-grid-new-zone.md)).
- Хэш группы SimGroup (поле 0x10) — хэш её потока в TOC; `EnableDisableStreams` с хэшем, которого нет в TOC, включает и выключает группу с таким хэшем (`0x00447AB0`).
- GUID потоков игра берёт из данных: `wgi` (ячейки зон и таблица потоков уровня) — 1 868 хэшей TOC из 2 287, SimGroup (`StreamSet`, `InterestingObject.8`, `Animated.4`, `Door.23` и др.) — 766. См. [зоны](zones.md).
- Выгрузка `0x00404C40` → `0x004048C0`: счётчики ссылок (`+0x54`, бит `0x20` в `+0x50` — «загружен явно»), рекурсивно зависимости, сообщения `iMsgStreamBeginUnload/Unloading/UnloadComplete`. Классы `LoadStream`/`UnloadStream` (`0x008139D0`, `0x00813BC0`) в SimGroup игры не используются.
- Чтение — на отдельном потоке кусками по 128 КБ (`ReadFile` из `0x00ABEC29`), открытие — `CreateFileW` из `0x00AC0BDF` (см. [файлы](file-system.md)). На старте `-stream gf2 cuba` через 5 с загружен 61 поток.
- Два запроса подряд роняют игру (этап 32): [модуль связи](live-module.md) держит очередь из одного запроса. Для незнакомого имени игра заводит запись «запрошен» навсегда.
- Подмена файлов: модуль меняет открытие файла (`redirect=ПУТЬ|ЦЕЛЬ` в `doctor_live.cfg`) — игра читает пересобранный поток из папки тулкита, её папка не меняется.

## Что неизвестно

- Смысл `u16 3` в заголовке потока.
- Откуда берутся GUID кадров роликов `igc*_s*`, банков `dlg\…` и корней уровней (вероятно, Trinity или код по имени).
- Биты TOC `0x2`, `0x8`, `0x10`, `0x20` на диске в GF2 не встречаются и не проверены.
- Подмена ресурса по GUID в памяти при загрузке (без копии потока) не сделана.
