# Хэши имён и сжатие

Движок почти везде заменяет имена 32-битными хэшами. Функций несколько; какая где — ниже.

## Что известно

- **SDBM**: `hash = c + hash * 65599`. Как есть — теги типов ресурсов (`tg4h`, `mesh`, `simgroup`; `sdbm("graph") = 0x3C572A4E`), имена политик [памяти](memory.md), id ресурсов `smb` и `sbk` (SDBM пути сборки `levels\<игра>\<уровень>\streams\…<тег>` в нижнем регистре).
- **SDBM нижнего регистра** (`0x004DAFD0`): имена сообщений [шины](message-bus.md), классы [SimGroup](simgroup-objects.md) (`Entity` = `0x38523FC3`), свойства и типы metamodel, кости, входы анимаций (`idle` = `0x46F5C7B4`), имена эмиттеров `.emx`, имена переменных сюжета, записи таблиц строк `lh2` (`0x004DB060`: `fe_press_start` → `cbd0a3c6`), имя ролика в `tob`.
- **CRC-32 нижнего регистра**: имена материалов (запись отрисовки меша ссылается на материал так), имена шейдеров; третий id текстуры (`ids[2]` у `tg4h`/`tg4d`) — CRC-32 имени пакета (`crc32("assets_shared_fonts") = f3d257db`, проверено на всех 28 246 текстурах).
- **Свёртка GUID** для TOC (отдельная функция `0x00401F40` — 4 вызова из менеджера потоков; та же формула в начале поиска записи `0x004A82B0` → `0x004A8180`): `((a·33 + b)·33 + c)·33 + d` по четырём little-endian словам GUID потока; GUID `a301c953 7450558d 4752414e 44515549` → `0x43BAECA2`. По имени хэш записи TOC не вычислить.
- **FNV-1a** входит в список функций словаря тулкита (`HashFn`: SDBM, CRC-32, FNV-1a, каждая и в нижнем регистре); известное применение — сам тулкит: детерминированные id новых ресурсов и ключи новых NeoGuid.
- Словарь имён (`lookup`, `unknown-hashes`) называет 552 704 из 556 394 мест хэшей записей (99,3 %); имя принимается, только если функция этого вида имён даёт хэш, который есть в игре.
- **Сжатие**: блоки `Rpak` потоков — RefPack (LZ-вариант EA, заголовок `10 FB`, 24-битный размер big-endian; пять классов опкодов); все 146 544 блока корпуса распаковываются в заявленный размер. LZX (`LZXD`) — только Dead Space, в GF2 не встречается. Игра принимает поток, целиком сжатый компрессором тулкита.

## Что неизвестно

- Хэш имени текстуры (`ids[3]`) не равен ни одной из функций от имени, пакета или пути (вероятно, хэш пути исходного ассета).
- Хэш записи `variabledictionary` (не SDBM, FNV-1a, FNV-1, djb2 и не CRC-32).
- Функция id мешей в `partsdb` (SDBM строки с неизвестным префиксом), хэш группы SimGroup, входы хэшей рига и наборов костей.
- Ключ lookup эмиттеров `sbk` — свёртка GUID ассета, по имени не вычисляется.
- Хэши имён свойств навигационных графов — без имён.
