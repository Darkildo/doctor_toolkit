# Формат: мировая сетка `wgi`

`wgi` (`type_id` `0x3B004EB9`, SDBM тега `wgi`) — мировая сетка уровня:
список потоков, которые игра сама грузит и выгружает по положению игрока, и
таблица остальных потоков уровня с их предпосылками. Издание — PC 1.0.789.0.

Источники: код `godfather2.exe` (адреса в тексте), скрипт
`research/wgi_survey.py` (все 28 ресурсов игры), корпусный тест
`every_world_grid_round_trips` (разбор → запись совпадает побайтно). Что
проверено в игре — §7.

## 1. Где лежит

В корневом потоке уровня (`gf2/cuba`, `gf2/miami`, `gf2/queens`, уровни
сетевой игры) — по одному `wgi` на объект `WorldGraphPartition` (`108dea4e`).
Раздел находит свой `wgi` среди ссылок объекта по типу ресурса (читатель
`0x00887E40`: SDBM строки `WGI` — это и есть `type_id`; поиск
`0x004B9CA0`; в JSON SimGroup — поле `links` объекта с id ресурса). В трёх
городах по четыре сетки, в уровнях сетевой игры по две:

| № в потоке | Маска LOD мировых ячеек | Что в ней (Нью-Йорк) |
|---|---|---|
| 0 | `0x01` высокая | зоны `high`, интерьеры (`0x10`), потоки заданий и заказов (маска 0) — 260 ячеек |
| 1 | `0x02` средняя | зоны `medium` — 40 |
| 2 | `0x04` низкая | зоны `low` — 12 |
| 3 | `0x08` вид карты | одна ячейка — поток карты «Взгляда дона» (`gf2\queens\global\dons_view\dv_zonestream`; в Гаване `…\dons_view\dons_view`, в Майами `…\dons_view\map_stream`) |

## 2. Раскладка

Все числа little-endian. Смещения — от начала ресурса; при загрузке игра
превращает их в указатели (`0x0088CC10`: проверяет `type_id` и версию 7,
прибавляет адрес ресурса к каждому ненулевому смещению).

```
0x00  u32  0x3B004EB9
0x04  u32  версия = 7
0x08  u32  смещение таблицы потоков = 0x20
0x0C  u32  число потоков S
0x10  u32  смещение ячеек = 0x20 + 24·S
0x14  u32  число ячеек C
0x18  u32  смещение пула = смещение ячеек + 128·C
0x1C  u32  число слов пула P
      S записей потоков по 24 байта
      C ячеек по 128 байт
      P слов пула по 4 байта; ресурс кончается сразу за пулом
```

Три части идут подряд без промежутков во всех 28 ресурсах.

### 2.1 Запись потока (24 байта)

| Смещение | Тип | Поле |
|---|---|---|
| 0x00 | 16 байт | GUID потока (NeoGuid с логином автора: `…BRINKER1`, `…SZAKAL20`) |
| 0x10 | u32 | число слов списка «нужные потоки» |
| 0x14 | u32 | смещение списка в пуле; 0, если списка нет (3 602 записи из 5 254) |

Свёртка GUID `((a·33 + b)·33 + c)·33 + d` — хэш записи потока в TOC
(`toc.md` §3); все 5 254 записи находятся в TOC. Таблица одинакова во всех
сетках одного уровня (195 записей в Гаване, 228 в Майами, 269 в Нью-Йорке).
В ней **нет** потоков ячеек: это потоки анимаций
(`gf2\globalfolder\interestingobjectanimations\…`), наборы заданий, папки
`local`/`global` уровня. Список записи — потоки, которые должны быть
загружены раньше; с предпосылками TOC он совпадает у 788 записей из 1 652
(у остальных сетка называет папку уровня, а TOC — `globals_global`).

### 2.2 Ячейка (128 байт)

| Смещение | Тип | Поле |
|---|---|---|
| 0x00 | 16 байт | GUID потока ячейки |
| 0x10 | u32 | хэш потока в TOC — свёртка GUID (совпадает у всех 1 483 ячеек) |
| 0x14 | 3 × f32 | центр: до него меряется расстояние от игрока |
| 0x20 | f32 | радиус описанной сферы |
| 0x24 | 12 байт | игра не читает; обычно нули, у 217 ячеек — мусор сборки |
| 0x30 | 4 × f32 | минимум коробки, `w` = 1; `FLT_MAX` у ячейки без коробки (136) |
| 0x40 | 4 × f32 | максимум коробки, `w` = 1; `−FLT_MAX` без коробки |
| 0x50 | u8 | вид ячейки, §3 |
| 0x51 | u8 | флаги: `0x01` — «всегда», `0x02`, `0x04`; биты `0x08` и `0x10` игра ставит в памяти сама |
| 0x52 | u16 | число слов списка по смещению 0x6C (0 или 1) |
| 0x54 | u32 | маска LOD: `0x01` высокая, `0x02` средняя, `0x04` низкая, `0x08` вид карты (у потока с ней коробка не регистрируется), `0x10` интерьер, 0 — у потоков заданий |
| 0x58 | f32 | наименьшее расстояние загрузки; 0 во всех ячейках |
| 0x5C | f32 | наибольшее расстояние загрузки; 0 — радиус раздела; 0 во всех ячейках |
| 0x60 | u32 | SDBM имени в нижнем регистре, по которому ячейку находит `ZoneStreamEnable`; 0 — без имени (196 ячеек с именем) |
| 0x64 | u32 | 0 |
| 0x68 | u32 | хэш потока связанной ячейки или `0xFE16702F` («нет»; связь есть у 18 ячеек) |
| 0x6C | u32 | смещение списка нужных потоков в пуле; 0 — нет (166 ячеек) |
| 0x70 | u32 | смещение следующей ячейки кольца; у одиночной — её собственное |
| 0x74 | 12 байт | игра не читает; нули или мусор сборки |

- Центр и радиус — не всегда центр и полудиагональ коробки (совпадают у 715
  и 663 ячеек из 1 347 с коробкой): похоже на сферу по геометрии зоны
  (догадка).
- Имя ячейки у 143 из 196 — последний компонент пути потока
  (`venue_115`); у остальных своё (`hitstream24`), и это то имя, что стоит в
  атрибуте 0 объекта `ZoneStreamEnable`.
- Список ячейки (одно слово) у 1 311 из 1 317 ячеек указывает на запись
  родителя потока по TOC (`gf2\cuba\local`). Код PC этот список не читает
  (чтений поля 0x6C ячейки в модуле сетки нет); предпосылки игра берёт из
  TOC (§5).
- Кольца связывают группы ячеек: несколько ячеек вида 0 с одной-двумя вида
  2 или 5, либо только вида 5 (2–5 штук), либо только вида 0. Длина кольца
  — от 1 (128 ячеек) до 60. Похоже на ячейки одного места — квартал с его
  потоками заказов, комнаты одного интерьера (догадка); код обходит кольцо
  только для видов 1, 3 и 6 (§3).

### 2.3 Пул

`P` слов, каждое — смещение записи потока. На каждое слово есть ссылка
(списки записей и ячеек пересекаются и делят слова): в 28 ресурсах 278 слов,
все использованы.

## 3. Виды ячеек

Узел ячейки в памяти имеет счётчик включений (`+0x18` узла). При постройке
(`0x0088C4F0`) он равен 1 у вида 0 и 0 у остальных; ячейка с нулевым
счётчиком не грузится.

| Вид | Число | Флаги | Что это | Кто включает |
|---|---:|---|---|---|
| 0 | 1 290 | 0 (1 245), `0x01` (22), `0x02` (23) | зоны мира: `high`, `medium`, `low`, небо, океан | включена всегда |
| 2 | 86 | `0x01` | потоки заданий, заказов и укреплений (`hitstream24`, `cp_325_zonestream`, `compoundstream`) | `ZoneStreamEnable` |
| 5 | 102 | 0 (72), `0x01` (30) | интерьеры (`venue_115`), часть потоков заказов | `ZoneStreamEnable` |
| 4 | 3 | 0 | три интерьера Майами | `ZoneStreamEnable` |
| 1 | 2 | `0x05` | два потока задания 8 в Гаване | `ZoneStreamEnable` |

Виды 1, 3 и 6 код выделяет особо (`0x0088A960`: если игрок внутри сферы
такой ячейки, её кольцо помечается битом `0x08`); в данных PC таких ячеек
две, обе вида 1.

## 4. Как игра решает, что грузить

Менеджер сетки — `*0x01129824`: разделы `+0x80` (число `+0x148`), наборы
мер `WorldGraphMetrics` — число `+0x7C`. Раз в кадр (`0x0088D6E0`):

1. Точка интереса — положение **игрока** (`*(*(0x012233A0 + 4))`,
   матрица `+0xD0`), а не камеры; камера берётся только при отладочном
   флаге `0x0112E242`. К ней добавляются ещё две точки впереди по ходу — на
   0,75 и 1,5 средней скорости за 15 кадров (скорость не больше 50 м/с;
   при скорости ниже 0,1 м/с все три точки совпадают).
2. Для каждого раздела (`0x0088A960`) у каждой ячейки считается
   приоритет: 0, если раздел выключен (атрибут 0) или счётчик включений 0;
   500 у ячейки с флагом «всегда»; иначе `(1 − d / R) · 100`, где `d` —
   расстояние от точки до центра, `R` — радиус раздела; берётся наибольший
   из трёх точек. Потоку, который уже запрошен или загружен, прибавляется 5.
3. Загрузка (`0x0088BB70`): ячейки сортируются по приоритету и идут, пока
   приоритет не ниже 10, число ячеек не больше атрибута 6 мер (64) и сумма
   `data_size` из TOC (вместе с включёнными дочерними потоками,
   `0x00888080`) не больше бюджета раздела — атрибут 4 мер в мегабайтах.
   Прошедшие запрашиваются (`0x0088AE10` → `0x00404280`), остальные
   загруженные выгружаются (`0x0088BAD0` → `0x0088AF60`).

Радиус раздела `R` (`+0x284`) на PC берётся не из данных: атрибут 2
`WorldGraphPartition` (150 и 300 в Нью-Йорке) читатель `0x00887E40`
пропускает. `R` ставится по маске мер при связывании (`0x0088C9C0`):

| Маска мер (атрибут 0) | `R` | Грузится до (приоритет ≥ 10) | Держится до (+5) |
|---|---:|---:|---:|
| бит `0x01` высокая | 200 м | 180 м | 190 м |
| бит `0x02` средняя | 500 м | 450 м | 475 м |
| бит `0x04` низкая | 2 000 м | 1 800 м | 1 900 м |
| иначе | 5 000 м | 4 500 м | 4 750 м |

Меры Нью-Йорка: маска 17 (высокая и интерьеры), бюджет 25 МБ; маска 2 —
20 МБ; маска 4 — 8 МБ; маска 8 (карта, меры в `globals_global`) — 8 МБ; лимит 64 потока, атрибут 5 = 2 у
всех. Атрибуты 1–3 мер PC не читает (`0x0088ED50`; вероятно, бюджеты других
платформ — догадка).

**Проверено в игре** (Гавана, чтение памяти модулем связи,
`game-bench.md` §33): у четырёх разделов `R` = 200, 500, 2 000 и 5 000 м,
прибавка 5, бюджеты 25, 20, 10 и 8 МБ, лимит 64. Расстояние на деле
ограничивает **бюджет**: зоны `high` весят по 2–3 МБ, и в плотном месте
(у ворот аэропорта) кроме двух ячеек «всегда» загружена 21 ближайшая, до
138 м; где зоны мельче — 18, до 175,5 м (приоритет 17,2). Обход идёт по
убыванию приоритета и останавливается на первой зоне, которая не влезла,
поэтому маленький поток дальше неё тоже не загрузится.

## 5. Предпосылки и дочерние потоки

- Перед запросом потока ячейки `0x0088AE10` идёт по предпосылкам его
  записи TOC (`f[0] + (f[2] & 1)` первых зависимостей) и запрашивает те,
  что есть в таблице потоков сетки (общая карта `0x00E541FC`, строится из
  таблиц всех разделов в `0x0088C4F0`, счётчик ссылок на поток);
  при выгрузке — обратно (`0x0088AF60`). Остальное делает загрузчик
  потоков (`new-resources.md` §3.1).
- У узла нет записи, если хэша ячейки нет в загруженных TOC
  (`0x00405720`): ячейка без записи TOC молча пропускается.
- Коробка ячейки (если она есть и маска без бита `0x08`) при загрузке
  регистрируется за потоком (`0x00429430`), при выгрузке снимается
  (`0x00429460`).

## 6. `ZoneStreamEnable`

Класс `c8f2456f` (конструктор `0x00890A80`). Читатель `0x00890BD0`: атрибут
0 — строка; её SDBM в нижнем регистре ищется среди имён ячеек всех разделов
(`0x0088DBF0` → `0x00888100`: двоичный поиск по полю 0x60, среди одноимённых
— ближайшая к объекту), узел запоминается в `+0x1C0`. На каждом тике
(`0x00890CB0`, сообщение `0x012069C4`) положение игрока переводится в
систему объекта: внутри единичного куба (±0,5 по каждой оси — то есть
внутри коробки, заданной масштабом матрицы объекта) счётчик включений узла
+1, при выходе −1.

Коробка объекта может быть повёрнута: у `venue_055` Гаваны оси матрицы —
(53,6; 0; 53,6) и (−79,1; 0; 79,1), то есть коробка 75,8 × 31,9 × 111,9 м
под 45°.

Следствия (первое и второе проверены в игре, `game-bench.md` §33):

- имя, которого нет ни в одной сетке, ничего не делает — поэтому
  `ZoneStreamEnable` «не работал» для нового потока (`game-bench.md` §28);
- поток грузится, только пока игрок внутри коробки объекта **и** ячейка
  ближе радиуса раздела (флаг «всегда» снимает второе условие);
- `ZoneStreamEnable` с флагом объекта `flags2 = 0` — шаблон, его создаёт
  `FuncSpawn`; узел он ищет при создании.

## 7. Новая ячейка

Чтобы новый поток грузился как зона города, в сетку высокой детализации
добавляется ячейка: GUID и хэш потока, коробка, центр и радиус, вид 0,
маска `0x01`, список из одного слова пула — записи родителя, кольцо из
самой себя. Смещения пересчитываются: ячейки стоят перед пулом, поэтому все
указатели в пул сдвигаются на 128 байт.

Тулкит: `resource::wgi::WorldGrid` (`parse`, `to_bytes`, `add_cell`,
`remove_cell`), `level::world_grid` (`add_zone_cell`, `remove_zone_cell`),
команда `doctor-toolkit world-grid info|add|remove`, инструмент MCP
`add_zone_cell`, пример `examples/zones/world-grid-zone.sh`.

**Проверено в игре** (`game-bench.md` §33): новый поток с ячейкой вида 0 в
сетке высокой детализации Гаваны загружается, когда игрок рядом (0, 60 и
100 м от центра), и выгружается вдали (300 м и дальше); то же в Нью-Йорке
(ячейка у точки появления: поток загружен сразу при входе в город,
выгружен в 800 м); ячейка вида 5 с именем грузится, пока игрок внутри
коробки нового `ZoneStreamEnable`.

Ограничения: ячейка считается в бюджет раздела по `data_size` своего потока
(тулкит пишет его в TOC сам), так что большой новый поток вытесняет дальние
зоны игры; GUID ячейки должен сворачиваться в хэш потока — у потока,
созданного `add-stream`, его знает рабочее пространство, для другого потока
GUID задаётся явно (`--guid`).

## 8. Открыто

- Смысл флагов ячейки `0x02` (23 ячейки вида 0) и `0x04`: в узле флаг
  `0x02` становится битом `0x10`, читатель этого бита не найден.
- Что делает коробка, зарегистрированная за потоком (`0x00429110`).
- Связанная ячейка (поле 0x68): узел связанного потока даёт +200 к
  приоритету загрузки, когда тот загружен (`0x0088BB70`); в игре не
  проверено.
- Атрибуты 1–3 `WorldGraphMetrics` и атрибуты 2–3 `WorldGraphPartition`:
  PC их не читает.
