# Формат: заведения города `bricknmortarres`

`bricknmortarres` (`type_id` `0xA31FF01E`, SDBM тега) — список заведений
города: предприятий, точек семей, укреплений. По нему игра находит заведение
каждого объекта `Building`. Издание — PC 1.0.789.0.

Источники:
- код `godfather2.exe` (адреса в тексте);
- все 8 ресурсов игры;
- корпусный тест `every_venue_table_round_trips`: разбор, затем запись совпадает с ресурсом побайтно;
- проверка на стенде 2026-11-18 (§5).

## 1. Где лежит

По одному ресурсу в корневом потоке каждого города и в уровнях сетевой игры:

| Поток | Заведений |
|---|---:|
| `gf2/queens` | 27 |
| `gf2/miami` | 48 |
| `gf2/cuba` | 38 |
| `mp_bonnie`, `mp_mall`, `mp_oil_refinery`, `wb_multiplayer` и др. | 1–2 |

## 2. Раскладка

Все числа little-endian, смещения — от начала ресурса.

```text
0x00  u32  16
0x04  u32  число заведений N
0x08  N записей по 0x70 байт
0x08 + N × 0x70  имена эффектов: строки с нулём на конце, шесть строк
                 каждого заведения подряд, в порядке заведений
```

Запись:

| Смещение | Тип | Что это | Где ещё |
|---|---|---|---|
| `+0x00` | 16 байт | GUID заведения; у нескольких заведений Гаваны и карт сетевой игры — нули | `Building.5` его здания |
| `+0x10` | u32 | исходный владелец: SDBM имени семьи в нижнем регистре (`rosato_carmine` `529e27ee`, `corleone` `0637b907`), 0 — нет | `Building.4` |
| `+0x14` | i32 | номер заведения (перечисление [`venue`](../kb/enums/venue.md)) | `Building.0` |
| `+0x18` | u32 | город: SDBM `newyork`, `florida`, `cuba` | `Building.3` |
| `+0x1C` | u32 | флаги | `Building.2` |
| `+0x20` | i32 | тип 0…9 (точки семей — 9) | `Building.1` |
| `+0x24` | u32 | 0, 4 или 8; игра хранит в `+0x50` заведения, смысл не установлен | — |
| `+0x28` | u32 | 20 (в одном заведении Гаваны 50); загрузчик не читает | `Building.16` |
| `+0x2C` | 3 × f32 | положение здания | положение `Building` |
| `+0x38` | 3 × f32 | вторая точка | — |
| `+0x44` | 3 × f32 | третья точка | — |
| `+0x50` | 2 × f32 | 8 и 22 у всех заведений игры | `Building.39`, `Building.40` |
| `+0x58` | 6 × u32 | смещения имён эффектов «Взгляда дона», 0 — нет | `Building.6`…`11` |

Имена эффектов: `dv_dons_light`, `dv_building_fire` (у заведения 50 —
`dv_building_fire_050`), `dv_building_embattled`, `dv_building_repairing`,
`dv_venue_closed`, `dv_building_bombers`.

## 3. Как игра его читает

1. Менеджер `BricknMortarRes`: конструктор `0x006B01E0`, деструктор `0x006B0580`.
2. При загрузке ресурса `0x006B1000` превращает шесть смещений каждой записи в указатели (прибавляет начало ресурса, нуль оставляет нулём).
3. `0x006AF5E0` строит по каждой записи объект заведения размером 0x1A0 байт (`0x006B2670`):
   - GUID → `+0x184`;
   - номер → `+0x38`;
   - владелец → `+0x3C` и `+0x40` (исходный и текущий);
   - город → `+0x48`;
   - флаги → `+0x34`;
   - тип → `+0xC4`;
   - поле `+0x24` записи → `+0x50`;
   - точки → `+0x10…+0x30`;
   - два числа → `+0x104`, `+0x108`.
4. Название на экране — строка `building_name_%03u` с номером заведения.
5. Объект `Building` при загрузке своего потока (сообщение `0x0120E93C`, обработчик `0x006AE7C0`) ищет заведение по номеру (`0x006B0EE0`: две отсортированные таблицы менеджера, `+0x28` и `+0x34`) и сразу работает с ним (`0x006B5B80`), без проверки на нуль.

**Номера общие для всех городов.** Заведения каждой загруженной таблицы игра
кладёт в одну таблицу менеджера, отсортированную по номеру (`0x006B1520` →
вставка `0x006B1280`). Повтор номера вставка не принимает и возвращает нуль,
и игра пишет по нему, как только загрузится вторая таблица с этим номером:
`0x006B153C`, запись по адресу 0. Так падала первая версия мода «Война с
Кармине» с заведением 230 (230 есть в Гаване). Номера трёх городов в игре не
повторяются (корпусный тест `venue_numbers_of_the_cities_are_unique`; у карт
сетевой игры 997 и 998 повторяются, но они вместе не грузятся). `venue add`
отказывает в номере, который есть в любой таблице игры.

**Здание с номером, которого нет ни в одной записи, роняет игру** при
загрузке своего потока: чтение `+0x16C` нулевого указателя в `0x006B5B87`.
Проверено на стенде (§5).

**Коллизию интерьера заведения игра ставит по его записи.** Копия банка (26)
с объектами, сдвинутыми на другое место, без записи своего номера не имеет
коллизии интерьера (люди и игрок стоят на земле под полом); с записью,
сдвинутой на то же смещение, и зданием `Building` в потоке интерьера — имеет
(стенд, `game-bench.md` §56). Копия места целиком — `level copy-zone`
(`docs/levels.md` §7.1).

## 4. Новое заведение

1. `doctor-toolkit venue add ИГРА gf2/queens --id 230 --like 202 [--owner rosato_carmine] [--position X,Y,Z]` — новая запись по образцу заведения того же города:
   - тип, флаги, эффекты и владелец берутся у образца;
   - точки сдвигаются вместе с положением;
   - GUID — новый, его печатает команда.
2. Здание: копия объекта `Building` (`level add` с образцом-зданием), `Building.0` = номер, `Building.5` = GUID записи. Своё `Building.25` — сообщение, которое игра шлёт, когда заведение переходит к игроку.
3. Строка `building_name_230` (`text-add`) — название на экране.
4. Маркер «Взгляда дона»: копия `ZoneRenderLOD` точки в `gf2/queens/global/dons_view/dv_zonestream` с `ZoneRenderLOD.1` = номер; запись заведения берёт GUID маркера (`venue add --guid`).

Прочие команды:
- `venue list` — список заведений;
- `venue set` — владелец, тип, флаги, место;
- `venue remove` — удалить заведение.

Все правки пишутся в рабочее пространство. Код — `resource::bricknmortar`,
`level::venues`.

## 5. Проверено в игре

Стенд 2026-11-18: старт `-stream gf2 queens`, рабочее пространство отдаётся
игре подменами, сообщения ловятся точками останова живой связи.

| Что | Результат |
|---|---|
| Копия здания точки 202 с номером 230 **без** записи | падение при загрузке `hank/high/terrain013`: `0x006B5B87`, чтение `0x16C` |
| Та же копия с записью (`venue add --id 230 --like 202`) и `Building.5` = GUID записи | поток грузится, игра идёт |
| Датчик `TestBuildingOwnership` (230, `corleone`) до захвата | «не Корлеоне» |
| `ChangeBuildingOwnership` (230 → `corleone`) | здание шлёт своё `Building.25` |
| Датчик после | «Корлеоне» |

Мод «Война с Кармине» (стенд §54), заведение 230 с записью `venue add`, зданием и строкой `building_name_230`:
- название на экране есть: после захвата игра пишет «Your men took over Carmine's Headquarters»; без строки — «Your men took over .»;
- на карте «Взгляда дона» заведение подсвечено (после захвата оранжевым) копией маркера `ZoneRenderLOD` потока `dv_zonestream` с `ZoneRenderLOD.1` = номер и тем же GUID, что у записи; силуэт — модель маркера-образца;
- значка на мини-карте у него нет, но его нет вблизи и у точек семей 203 и 206.

Не проверено:
- доход;
- захват руками (не из логики);
- сохранение и загрузка с новым заведением (по коду: восстановление `0x006B1190` проходит мимо записей, которых нет у заведений).
